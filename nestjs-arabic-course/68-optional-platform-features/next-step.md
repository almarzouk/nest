# نهاية المسار

المسار من المقدمة حتى اعتمادية رف وأدوات CLI اكتمل. هذا الفصل يزيد ميزات عند الحاجة فقط.

`@nestjs/i18n` يحل لغة العرض مرة لكل طلب. `@nestjs/mail` يصيّر قالبًا ويُرسل بعد الالتزام. `@nestjs/storage` يحفظ الغلاف بعد فحص البايتات ويبقي الفاتورة خلف توقيع. `@Sse` يدفع حالة إلى تبويب مفتوح ويغلق المورد عند القطع. Serverless يختصر الدالة ويجعل الإقلاع جزءًا من الزمن، والأرقام المنشورة قياس لا عقد. التطبيق الهجين يفتح HTTP مع `connectMicroservice`، ووراثة الحراس ليست افتراضية: https://docs.nestjs.com/faq/hybrid-application

عقد REST، وعزل المنظمة، وحدث Stripe الموقّع، وصندوق الصادر، تبقى سارية سواء أضفتم هذه الحزم أم لا.
