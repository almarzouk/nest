# ما هو ORM

## الهدف من هذا الدرس

تعريف طبقة تربط الجداول بكائنات TypeScript، وحدّ ما لا تغطيه: القيود، والترحيل، وقرار أي أداة.

## المشكلة التي يحلها

جمل SQL المكررة في كل خدمة تعيد أسماء الأعمدة كنصوص. خطأ إملائي في `titl` يظهر عند التشغيل. تحويل صف `{ published: true }` إلى معنى المكتبة يتكرر. الفريق يريد أن يرى `book.title` لا `row["title"]`.

## الفكرة ببساطة

ORM يصف الجداول في كود أو في ملف مخطط، ويولّد دوال قراءة وكتابة تعيد كائنات. أنت تستدعي `findUnique` أو `save`. الأداة تبني SQL مربوطًا. ما زلت تحتاج أن تفهم الجدول والمفتاح الأجنبي، لأن الاستعلام السيئ يبقى بطيئًا بعد تغليفه.

## التعريف التقني

Object-Relational Mapping: مطابقة بين صف علائقي وكائن. ليست قاعدة بيانات، وليست بديلًا عن PostgreSQL في هذه الدورة.

توثيق Nest الحالي في قسم Data يذكر تكاملات يحافظ عليها الفريق أو يوثّقها:

- TypeORM عبر `@nestjs/typeorm`: كيانات بزينة ومستودعات.
- Drizzle عبر `@nestjs/drizzle`: جداول دوال TypeScript ومنشئ استعلام.
- Prisma: عميل يُولَّد من `schema.prisma`، بلا حزمة Nest خاصة. تكشفه بمزوّد.
- MongoDB عبر `@nestjs/mongoose`، و Sequelize عبر `@nestjs/sequelize`، و MikroORM عبر `@mikro-orm/nestjs`.

هذه الدورة تشرح الفكرة ثم تكمل التطبيق على Prisma. TypeORM و Drizzle درسان لأن Nest يوثّقهما كمسارين. MongoDB و Sequelize و MikroORM خيارات موجودة في التوثيق، بلا فصول مستقلة هنا، حتى لا تتفرع قبل إتقان مسار واحد.

`synchronize` الذي يعدّل الجداول من الكيانات عند الإقلاع ليس ترحيلًا آمنًا للإنتاج. الترحيل ملف SQL محفوظ يُعاد على كل بيئة.

## Mental Model

```text
نموذج Book في الكود  ->  ORM  ->  SQL  ->  جدول books
        ^                                      |
        |______________ كائن Book _____________|
```

النموذج ليس الصف. الصف في القرص. الكائن في الذاكرة بعد القراءة.

## أبسط مثال

```ts
type BookRow = { id: number; title: string; published: boolean };

function toBook(row: BookRow) {
  return { id: row.id, title: row.title, published: row.published };
}
```

هذا أصغر mapper تكتبه بيدك. ORM يولّد مثله مع دوال `create` و `update` واستعلامات العلاقات، ويواكب تغيير الأعمدة إن أعدت التوليد أو أعدت الترجمة.

## شرح المثال

الدالة لا تفتح اتصالًا. هي الحد الذي يمنع بقية التطبيق من اعتماد شكل المشغّل. Prisma يضع هذا الحد في العميل المولَّد: نوع `Book` وحقل `prisma.book`. TypeORM يضعه في صنف كيان ومستودع. Drizzle يضعه في `pgTable` وأنواع `$inferSelect`.

إن تغيّر اسم العمود في SQL ولم يتغيّر النموذج، القراءة تنكسر. الترحيل والنموذج يتحركان معًا.

## ماذا يحدث داخليًا؟

الأداة تبني جملة `INSERT` أو `SELECT` بمعاملات، لا بلصق النصوص، ما دمت تستخدم واجهتها العادية. الاستعلام الخام الذي يلصق مدخلًا يعيد خطر الحقن. N+1 يحدث حين تجلب قائمة كتب ثم تنفّذ استعلام مؤلف لكل كتاب داخل حلقة. ORM لا يمنع ذلك تلقائيًا. التحميل في استعلام واحد، أو `include` في Prisma، قرار تكتبه.

الهوية: صفان بنفس المفتاح هما الشيء نفسه في القاعدة حتى لو نسخت الكائن مرتين في الذاكرة.

## مثال عملي

خدمة تعرض كتابًا ومؤلفه. بلا ORM تكتب `join` وتمرّر صفًا مسطحًا. مع ORM تطلب الكتاب ومعه علاقة المؤلف وتستلم شجرة. الفصل العملي يكتب ذلك في Prisma. إن احتجت تقريرًا بإحصاء لا يشبه كيانًا، SQL الصريح عبر العميل ما زال متاحًا، بمعاملات مربوطة.

## أخطاء شائعة

- ظن أن ORM يلغي الحاجة إلى مفتاح أجنبي.
- تشغيل مزامنة المخطط على الإنتاج.
- إرجاع كيان ORM كامل إلى JSON وفيه حقول داخلية.
- فتح ثلاثة ORMs على الجدول نفسه.

## متى نستخدمه؟

عندما تتكرر عمليات الصفوف والعلاقات وتريد أنواعًا تواكب المخطط.

## متى لا نستخدمه؟

لاستعلام تحليلي طويل أسهل كـ SQL واحد واضح، أو لمثال من عشر دقائق لا جدول له أصلًا.

## مقارنة

| SQL في الخدمة | ORM |
| --- | --- |
| الجملة ظاهرة | الجملة تُبنى من استدعاء |
| الأنواع يدوية | أنواع من المخطط أو الكيان |
| الترحيل ما زال مطلوبًا | الترحيل ما زال مطلوبًا |

## تمارين

### تمرين سهل

هل ORM يستبدل PostgreSQL؟

<details>
<summary>الحل</summary>

لا. هو طبقة في التطبيق تتحدث إلى القاعدة. الجداول تبقى في PostgreSQL.

</details>

### تمرين متوسط

لماذا لا يكفي تشغيل التطبيق ليحدّث جدول الإنتاج من الكيانات؟

<details>
<summary>الحل</summary>

المزامنة التلقائية قد تضيف أو تسقط أعمدة بلا أثر يُراجع. الترحيل ملف محفوظ يُطبَّق بترتيب معروف.

</details>

### تمرين متقدم

قائمة عشرين كتابًا نفّذت واحدًا وعشرين استعلامًا. ماذا حدث؟

<details>
<summary>الحل</summary>

استعلام للقائمة ثم استعلام لكل علاقة داخل حلقة. اطلب العلاقة مع القائمة في استعلام واحد أو بعدد ثابت، لا بعدد الصفوف.

</details>

## أسئلة مراجعة

- ماذا يطابق ORM بين العالمين؟
- أي أدوات يوثّقها Nest في قسم Data؟
- أي أداة ستكمل عليها الدورة؟

## الخلاصة

ORM يولّد وصولًا ذا نوع إلى جداول تعرفها أصلًا. Prisma مسارنا التطبيقي. TypeORM و Drizzle بديلان موثّقان. البقية تُذكر حتى تعرف أنها موجودة.
