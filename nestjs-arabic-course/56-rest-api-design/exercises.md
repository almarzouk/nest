# تمارين الفصل

## تمرين سهل — صحح العقد

راجع هذه الردود واقترح التصحيح:

1. `GET /getAllBooks` → 200 و `[{...}]`
2. `GET /books?author=غير-موجود` → 404
3. `POST /books` أنشأ صفًا → 200 و `{ id }`

<details>
<summary>الحل</summary>

1. `GET /books`. 2. 200 و `{ "data": [], "nextCursor": null }`. 3. 201 مع الجسم الذي يحتوي `id`.

</details>

## تمرين متوسط — مفتاح وجسم

عميل أرسل `Idempotency-Key: K` فخُزّن 201 لكتاب `b1`. أعاد K مع عنوان مختلف ثم أعاد K مع العنوان الأصلي. ما الردان؟

<details>
<summary>الحل</summary>

الثاني 409 `idempotency_conflict` ولا يُنشأ صف. الثالث، إن طابق المعنى المخزن، يعيد 201 و `b1` كما في المحاولة الأولى. إن اعتبرتم أي اختلاف لاحق تلويثًا للمفتاح، فالثابت في العقد: الجسم المختلف لا يُنفَّذ، والجسم المطابق يعيد المخزن.

</details>

## تمرين متقدم — وثيقة v2

اكتب خمسة أسطر عقد لـ v2 إذا تغيّر `price` فقط، بحيث لا ينجرف الترتيب ولا شكل الخطأ ولا رمز القائمة الفارغة.

<details>
<summary>الحل</summary>

1. المسار `/v2/books` (أو نفس المسار مع الترويسة المتفق عليها).
2. `price` كائن `{ amount, currency }`.
3. `GET` القائمة 200 مع `{ data, nextCursor }` وحتى عند الفراغ.
4. `POST` 201 مع `Idempotency-Key` ونطاق المفتاح يتضمن النسخة.
5. الأخطاء `{ statusCode, code, message }` و `book_not_found` عند غياب الفرد.

</details>
