التمهيد للفصل التالي

العناوين التي ضبطتها، billing و redis و nats، لا تعمل على جهازك كما تعمل داخل شبكة الحاويات. localhost من صورة التطبيق هو الحاوية نفسها. الفصل التالي يضع Nest و PostgreSQL و Redis في Docker: صورة متعددة المراحل، وأمر تشغيل node dist/main.js لا start:dev، و Compose يسمي الخدمات التي تصبح مضيفات.

ستحتاج Node 20.19 أو أحدث، أو 22.12 أو أحدث، في الصورة. البناء npm run build ثم تشغيل الناتج. قاعدة البيانات مضيفها اسم الخدمة postgres داخل DATABASE_URL.
