# Enums

## الهدف من هذا الدرس

معرفة شكل Enum في TypeScript، ومتى يكون اتحاد نصوص أنسب في كود Nest.

## المشكلة التي يحلها

حالة الطلب ليست أي نص. لو كانت `string`، يُقبل `'shiped'` بغلط إملائي. نريد مجموعة مغلقة يعرفها المترجم.

## الفكرة ببساطة

`enum` يسمي مجموعة قيم. TypeScript يدعم enums رقمية ونصية. الاتحاد النصي `'draft' | 'published'` يؤدي غالبًا الغرض نفسه لحالّات API، ويُمحى بطريقة أسهل.

## التعريف التقني

Enum النصي ينتج كائن JavaScript حي: يمكن أن يُستورد كقيمة. Enum الرقمي له تعيين عكسي من العدد إلى الاسم. الاتحاد النصي نوع فقط ويُمحى، إلا إذا احتجت القيمة كشيء تمرره وقت التشغيل فتعرّفها ثابتًا.

توثيق Nest يستخدم enums في أماكن مثل GraphQL (`registerEnumType`) عندما يجب أن تظهر القيمة في المخطط. للأنواع الداخلية، الاتحاد يكفي كثيرًا.

## Mental Model

```text
اتحاد نصي     فحص كتابة فقط
enum نصي      كائن وقت التشغيل + نوع
enum في GraphQL  يجب أن يعيش ليبني المخطط
```

## أبسط مثال

```ts
enum OrderStatus {
  Draft = 'draft',
  Paid = 'paid',
}

function label(status: OrderStatus): string {
  return status;
}
```

## شرح المثال

- `OrderStatus.Draft` القيمة `'draft'`.
- المعامل يقبل أعضاء الـ enum.
- الناتج JavaScript كائن `OrderStatus` تقريبًا بالشكل `{ Draft: 'draft', Paid: 'paid' }`.
- يمكن تمرير `label(OrderStatus.Paid)`.

الاتحاد المقابل:

```ts
type OrderStatusName = 'draft' | 'paid';
```

لا كائن وقت التشغيل. النداء `label('paid')` إن كانت الدالة تقبل الاتحاد.

## ماذا يحدث داخليًا؟

المترجم يولد الكائن للـ enum. هذا من المواضع القليلة التي ينتج فيها النوع أثرًا وقت التشغيل. لذلك استيراده يجب أن يكون استيراد قيمة لا `import type` إذا استخدمت `OrderStatus.Draft` في التعبيرات.

Enum الرقمي من غير قيم صريحة يعطي 0 ثم 1. في JSON الـ API العدد أقل وضوحًا من النص `'paid'`. فضّل النصوص على حدود HTTP.

## مثال عملي

في خدمة، قارن الحالة بالنص الثابت من الـ enum حتى لا تتفرق السلاسل:

```ts
function canCancel(status: OrderStatus): boolean {
  return status === OrderStatus.Draft;
}
```

لو كتب كل مطور `'Draft'` و `'draft'` و `'DRAFT'` فالتساوي ينكسر. مكان واحد للقيمة يغلق ذلك. الاتحاد مع ثابت كائن `as const` بديل حديث:

```ts
const OrderStatus = {
  Draft: 'draft',
  Paid: 'paid',
} as const;

type OrderStatus = (typeof OrderStatus)[keyof typeof OrderStatus];
```

هذا النمط شائع لأن الكائن والنوع بالاسم نفسه، والقيم نصوص واضحة. استخدمه عندما لا تحتاج ميزة خاصة بالـ enum. عندما يفرض الدرس الرسمي enum، مثل تسجيل enum في GraphQL، استخدم enum كما في الصفحة.

## أخطاء شائعة

- Enum رقمي في JSON العام. العميل يرى `0` بلا معنى.
- `import type { OrderStatus }` ثم استخدام `OrderStatus.Draft` كقيمة. الاستيراد النوعي يُحذف.
- إضافة عضو جديد ونسيان كل `switch`. فعّل فحص الاكتمال بإرجاع النوع `never` في الفرع الأخير عندما يكبر العدد.

## متى نستخدم enum؟

عندما تحتاج الكائن والقيمة معًا، أو عندما تطلب صفحة Nest الرسمية enum (GraphQL مثلًا).

## متى لا نستخدمه؟

لمجموعة صغيرة على حدود TypeScript فقط. اتحاد النصوص أخف. ولقيم تأتي من قاعدة البيانات بلا فحص: الـ enum لا يرفض نصًا خامًا حتى تفحصه.

## مقارنة

| | Union نصي | Enum نصي |
| --- | --- | --- |
| وقت التشغيل | لا أثر | كائن |
| JSON واضح | نعم | نعم إذا كانت القيم نصوصًا |
| استيراد | نوع | قيمة ونوع |

### تمرين متوسط

حوّل `type Role = 'customer' | 'staff'` إلى نداءات لا تتكرر فيها السلاسل يدويًا في أكثر من ملف. اذكر حلًا واحدًا.

<details>
<summary>الحل</summary>

كائن `as const` مشترك، أو enum نصي، يُستورد من ملف واحد. بقية الملفات تقارن بـ `Role.Staff` لا بكتابة `'staff'` في كل مكان.

</details>

### تمرين متقدم

لماذا قد يفشل `switch` على enum رقمي إذا وصلت القيمة `99` من JSON؟

<details>
<summary>الحل</summary>

الـ enum لا يغلّف JSON. `99` عدد لا يطابق الأعضاء، وفرع `default` إن غاب يترك السلوك ناقصًا. افحص القيم الداخلة إلى التطبيق قبل أن تعاملها كعضو enum.

</details>

## أسئلة مراجعة

- ما الذي ينتجه enum النصي وقت التشغيل ولا ينتجه الاتحاد؟
- لماذا النصوص أوضح من الأرقام على حدود API؟
- متى يفرض GraphQL في Nest الحديث عن enum بشكل حي؟

## الخلاصة

Enum مجموعة قيم قد تعيش ككائن. للحدود الداخلية اتحاد النصوص يكفي غالبًا. على الشبكة افحص القيمة، ولا ترسل أرقامًا غامضة.

## ماذا بعد؟

Nest مبنية على أصناف. الدرس التالي: الصنف والـ constructor من غير اختصارات.
