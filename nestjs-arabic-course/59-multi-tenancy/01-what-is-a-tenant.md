# ما هو Tenant

## الهدف من هذا الدرس

تعريف المستأجر في رف بأنه مكتبة لها بيانات وعملاء وحد فاتورة، لا بأنه عمود اختياري على جدول الكتب.

## المشكلة التي يحلها

رف بدأ لمكتبة واحدة. ثم دخلت مكتبة ثانية على نفس العملية فرأت كتب الأولى في `GET /books` لأن الاستعلام بلا حد. «المستأجر» صار كلمة في الاجتماع من غير أن يُعرف ما الذي يُعزل: الصفوف، الملف، أم قاعدة كاملة.

## الفكرة ببساطة

المستأجر طرف يستخدم المنتج كأنه له وحده. في رف المستأجر مكتبة. المستخدم إنسان داخل مكتبة أو عبر عضوية. الطلب دائمًا يعمل «نيابة عن مستأجر». الخلط بين المستخدم والمستأجر يجعل موظفًا في مكتبتين يرى اتحاد الكتالوجين.

## التعريف التقني

عزل المستأجرين ثلاثة نماذج شائعة تُسمّى أحيانًا pool و bridge و silo: مخطط مشترك فيه عمود `tenantId` (pool)، أو schema لكل مستأجر داخل قاعدة واحدة (bridge)، أو قاعدة لكل مستأجر (silo). الدروس التالية تفصل التكلفة. هذا الدرس يثبت الحدود: كل صف عمل (كتاب، طلب، عضو) ينتمي إلى مستأجر واحد. الهوية من الفصل السابق تقول من الشخص. المستأجر يقول أي مكتبة. لا يُؤخذ `tenantId` من جسم الطلب؛ المصدر مضيف أو ترويسة موثوقة أو مطالبة في رمز وقّعتموه. كل استعلام لاحقًا يقيّد بهذا المعرّف.

## Mental Model

```text
مستخدم  ـعضوية→  مكتبة (tenant)
الطلب يحمل مكتبة واحدة
الكتب التي تُعاد ⊆ كتب هذه المكتبة
```

## أبسط مثال

```ts
export interface ShelfTenant {
  id: string;
  name: string;
}

export interface ShelfUser {
  id: string;
  memberships: { tenantId: string; role: string }[];
}
```

## شرح المثال

- المستخدم بلا عضوية لا يفتح كتالوجًا.
- عضويتان تعنيان مكتبتين، والطلب يختار واحدة لا الاثنتين.
- `ShelfTenant.id` هو الذي سيدخل `where` لا اسم المكتبة المعروض.

## ماذا يحدث داخليًا؟

1. المصادقة تعرف `user.id`.
2. طبقة لاحقة تختار `tenantId` من مصدر موثوق وتتحقق أن لهذا المستخدم عضوية فيه.
3. الخدمات تقرأ المعرّف من هذا السياق لا من `@Body()`.
4. الاستعلام يضيف القيد في كل قراءة وكتابة.
5. غياب القيد خلل أمن لا خلل عرض.

## مثال عملي

رفض الطلب الذي يسمّي مكتبة لا ينتمي إليها الشخص:

```ts
export function assertMembership(user: ShelfUser, tenantId: string) {
  const member = user.memberships.find((item) => item.tenantId === tenantId);
  if (!member) throw new Error('not a member of this tenant');
  return member.role;
}
```

الخطأ هنا قاعدة عزل. ترجمته 403 على الحد، لا 404 الذي يكشف أو يخفي وجود المكتبة حسب عقدكم المكتوب. المهم أنه لا يُستبدل بصمت بمكتبة أخرى.

## أخطاء شائعة

- اعتبار كل مستخدم مستأجرًا حتى عندما تكون الفاتورة على المكتبة.
- عمود `tenantId` يقبل `null` «للبيانات العامة» ثم تُنسى في الاستعلام.
- أخذ المكتبة من `body.tenantId` لأن النموذج أرسلها.
- مشاركة كاش بلا مفتاح المستأجر بين المكتبات.

## متى نستخدمه؟

من أول جدول عمل في رف متعدد المكتبات. حتى لو بدأتم بمكتبة واحدة، العمود أو الحد يُقرران قبل البيانات الحقيقية.

## متى لا نستخدمه؟

لا تعزلوا جداول المرجع العالمية (قائمة عملات) كمستأجر. ولا تنسخوا عملية Nest لكل مكتبة يدويًا وتسموا ذلك تعريفًا؛ ذلك خيار نشر للنموذج silo لا تعريف الكلمة.

## مقارنة

| | مستخدم | مستأجر |
| --- | --- | --- |
| في رف | موظف أو قارئ بحساب | مكتبة |
| الفاتورة | لا | نعم عادة |
| ماذا يعزل | صلاحية الشخص | صفوف المكتبة |

## تمارين

### تمرين سهل

موظف في مكتبتين. كم `tenantId` يصح أن يراه طلب واحد؟

<details>
<summary>الحل</summary>

واحد. الطلب يختار مكتبة. التنقل بين المكتبتين طلبان بسياقين، لا اتحاد في استعلام واحد.

</details>

### تمرين متوسط

لماذا `tenantId` في JSON الإنشاء لا يكفي حتى لو طابق عضوية المستخدم؟

<details>
<summary>الحل</summary>

لأن العميل يختار القيمة. المصدر يجب أن يكون قناة لا يوقّعها جسم حر: مضيف، ترويسة من بوابة موثوقة، أو مطالبة داخل رمز تحققتم من توقيعه، ثم تُفحص العضوية. الجسم يمكن أن يخالف ذلك بسهولة.

</details>

### تمرين متقدم

بيانات «كتب مقترحة لكل المكتبات». أين تعيش حتى لا تكسر تعريف المستأجر؟

<details>
<summary>الحل</summary>

في كتالوج مرجعي بلا `tenantId` أو بمستأجر نظام صريح للقراءة فقط. نسخها إلى مكتبة يتم بصف جديد يملك `tenantId` تلك المكتبة. الاستعلام التشغيلي لا يقرأ المرجع والصفوف معًا من غير شرط مكتوب.

</details>

## أسئلة مراجعة

- ما المستأجر في رف؟
- ما الفرق بينه وبين المستخدم؟
- أي النماذج الثلاثة ستُفصَّل لاحقًا؟
- من أين لا يُؤخذ `tenantId`؟

## الخلاصة

المستأجر مكتبة تُعزل بياناتها. المستخدم عضو فيها. الطلب يحمل مستأجرًا واحدًا من مصدر موثوق، وكل استعلام عمل يقيّد به. الجسم ليس هذا المصدر.

## ماذا بعد؟

أرخص عزل في البداية: قاعدة واحدة ومخطط واحد وعمود على كل صف. الدرس التالي هذا النموذج (pool).
