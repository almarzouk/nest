# Root Module

## الهدف من هذا الدرس

فهم أن `AppModule` نقطة البداية التي يبني منها الإطار كل الرسم، لا مجرد ملف إعداد عادي.

## المشكلة التي يحلها

من غير جذر، لا يعرف الإطار أي المتحكمات تُنشر وأي المزوّدات تُنشأ. استيراد الملفات في `main.ts` واحدًا واحدًا يعيد قائمة مسطحة بلا حدود.

## الفكرة ببساطة

Root Module الوحدة التي تمررها إلى `NestFactory.create`. في القالب اسمها `AppModule` في `app.module.ts`. منها يُبنى application graph.

## التعريف التقني

فصل Modules: كل تطبيق فيه وحدة واحدة على الأقل هي الجذر. التطبيق الصغير قد يكتفي بها. التطبيق الحقيقي يستورد وحدات ميزات داخل `imports`. الجذر لا يُحقن كمزوّد عادي؛ هو وصف انطلاق.

## Mental Model

```text
create(AppModule)
    |
    +-- imports: وحدات ميزات
    +-- controllers: متحكمات هذا الملف
    +-- providers: مزوّدات هذا الملف
```

## أبسط مثال

```ts
import { Module } from '@nestjs/common';
import { AppController } from './app.controller.js';
import { AppService } from './app.service.js';

@Module({
  controllers: [AppController],
  providers: [AppService],
})
export class AppModule {}
```

## شرح المثال

- `@Module` يسجل Metadata الكائن.
- `controllers` أصناف تُنشأ وتُربط مساراتها.
- `providers` ما تستطيع الحاوية حقنه هنا.
- لا `imports` بعد. الرسم عقدة واحدة.
- الصنف فارغ الجسم. الوصف في الزينة. حقن مزوّد داخل صنف الوحدة ممكن لاحقًا للتهيئة، والتوثيق يحذّر أن صنف الوحدة نفسه لا يُحقن كمزوّد بسبب دورات.

## ماذا يحدث داخليًا؟

`create` يقرأ Metadata الجذر، ثم Metadata كل وحدة في `imports`، بشكل متحمّس: تحميل التطبيق يحمّل الوحدات حتى التي لن يُستخدم مسارها في أول طلب. التحميل الكسول استثناء لاحق (`LazyModuleLoader`). الرسم الناتج هو خريطة العلاقات التي تحل بها الحاوية الاعتماديات.

## مثال عملي

عندما تضيف كتبًا، الجذر يستورد الوحدة ولا يعيد إعلان خدمة الكتب:

```ts
@Module({
  imports: [BooksModule],
})
export class AppModule {}
```

هذا الشكل يصبح صادقًا بعد فصل Modules. المعاينة هنا حتى ترى أن الجذر فهرس وحدات لا سلة كل الأصناف.

## أخطاء شائعة

- تسجيل كل متحكمات المنتج في `AppModule` إلى الأبد.
- نسيان تمرير الجذر إلى `create` وتمرير متحكمًا بدلًا منه.
- اعتبار وجود `app.module.ts` كافيًا إن استوردت وحدة لا تصدّر ما تحتاجه. التصدير درس لاحق، والفشل يظهر عند الإقلاع لا عند حفظ الملف.

## متى نكتفي بالجذر؟

في قالب Hello World وأمثلة اللغة القصيرة.

## متى نخرج منه؟

عند أول ميزة لها متحكم وخدمة خاصة. تُنقل إلى Feature Module وتُستورد.

## مقارنة

| | استيراد ملفات في main | Root Module |
| --- | --- | --- |
| من يعلن القطع | قائمة متفرقة | Metadata واحدة تتفرع |
| الحدود | ضعيفة | `imports` و `exports` |

## أسئلة مراجعة

- ماذا يبدأ من Root Module؟
- ماذا تحتوي `controllers` مقارنة بـ `imports`؟
- هل صنف الوحدة الجذر مزوّد يُحقن في أي مكان؟

## الخلاصة

`AppModule` جذر الرسم. القالب يسجل عليه متحكمًا وخدمة. الميزات اللاحقة وحدات تُستورد لا ملفات تُكدس في `main.ts`.
