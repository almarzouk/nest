لمحة عن SWC

الهدف من هذا الدرس

معرفة متى تسرّع البناء من غير أن تفقد Metadata التي يحتاجها الحقن.

المشكلة التي يحلها

مترجم TypeScript الكامل دقيق ومهم في build، وقد يكون أبطأ أثناء حلقة الحفظ في مشروع كبر. SWC مترجم سريع مكتوب بلغة أنظمة، والتوثيق يعرضه كبنّاء.

الفكرة ببساطة

أضف -b swc إلى أمر البدء أثناء التطوير إن أردت بناءً أسرع. لا تفقد emitDecoratorMetadata.

التعريف التقني

First steps: npm run start -- -b swc. وصفة SWC في التوثيق تشرح التثبيت والتكامل. Vitest في قوالب Nest الحديثة يستخدم مسارًا يدعم Metadata التصميم (مثل SWC) لأن مترجمًا لا يصدرها يكسر الحقن في الاختبارات. هذا تفصيل واجهناه في فصل TypeScript.

Mental Model

حفظ الملف -> SWC يترجم بسرعة -> Node يشغّل الناتج مع Metadata

أبسط مثال

npm run start -- -b swc

شرح المثال

-- يمرر العلم إلى السكربت. -b swc يختار البنّاء. إن لم تكن الحزم مثبتة، وصفة التوثيق تذكر ما يضاف. لا تعتبر العلم سحرًا يعمل بلا إعداد إن رفضه CLI.

ماذا يحدث داخليًا؟

SWC يحوّل TypeScript إلى JavaScript ويستطيع إصدار زينة التصميم التي تقرأها reflect-metadata. أداة تترجم الأنواع بحذف الزينة تجعل المسارات أو الحقن يفشلان رغم أن الكود يبدو صحيحًا في المحرر.

مثال عملي

ابدأ بمترجم القالب الافتراضي حتى ترى أول مشروع يعمل. انتقل إلى SWC عندما تصبح إعادة التشغيل بطيئة. أبقِ nest build الذي تستخدمه للإنتاج قادرًا على إصدار Metadata نفسها.

أخطاء شائعة

  • تشغيل الاختبارات بمترجم يتجاهل الزينة ثم اتهام الحقن بأنه مكسور.
  • خلط أعلام webpack القديمة مع SWC من دروس متفرقة.
  • اعتبار SWC بديلًا عن فهم الأنواع. هو يسرّع الترجمة لا التصميم.

متى نستخدمه؟

عندما يبطؤ start:dev في مشروع متعدد الوحدات.

متى لا نستخدمه؟

ليس مطلوبًا لفهم Hello World.

مقارنة

tsc عبر المسار الافتراضي SWC
السرعة في الحفظ أبطأ غالبًا أسرع
Metadata مطلوبة يجب أن تبقى مفعلة
دورك الآن الافتراضي اختياري

تمارين

تمرين سهل

ما العلم الذي يمرر SWC لأمر البدء كما في First steps؟

الحل

-b swc بعد --.

تمرين متوسط

لماذا يفشل الحقن إذا ترجم الاختبار الأنواع وحذف Metadata؟

الحل

لأن design:paramtypes لا يُكتب، والحاوية لا ترى صنف المعامل.

تمرين متقدم

ما الفرق بين اختيار SWC للتطوير واختيار Rspack في monorepo؟

الحل

SWC مسار ترجمة سريع للتطبيق. Rspack في CLI 12 بنّاء الحزم الافتراضي لمساحات العمل متعددة المشاريع، بديلًا عن webpack الذي أصبح deprecated في ذلك السياق. تطبيقنا الأول لا يحتاج قرار monorepo.

أسئلة مراجعة

  • متى تجرب SWC؟
  • ماذا يجب ألا تضيع عند تغيير المترجم؟
  • هل SWC مطلوبة للفصل التالي؟

الخلاصة

SWC يسرّع الترجمة بشرط إبقاء Metadata الزينة. الافتراضي يكفي حتى يكبر المشروع.

ماذا بعد؟

ملف الأمثلة يثبت أول تشغيل، ثم التمارين، ثم نقرأ bootstrap سطرًا سطرًا.
