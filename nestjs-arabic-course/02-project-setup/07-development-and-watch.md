# التطوير ووضع المراقبة

## الهدف من هذا الدرس

تشغيل الخادم وإعادة التحميل عند حفظ الملف.

## المشكلة التي يحلها

إيقاف العملية وتشغيلها يدويًا بعد كل سطر يقطع سلسلة الفهم. وضع المراقبة يعيد الترجمة والإقلاع عند التغيير.

## الفكرة ببساطة

`npm run start` يشغّل مرة. `npm run start:dev` يراقب الملفات ويعيد التشغيل.

## التعريف التقني

First steps: `npm run start` يستمع على المنفذ في `main.ts`، أي `process.env.PORT` أو 3000، ويفتح `http://localhost:3000/` على رسالة Hello World. `npm run start:dev` يعيد الترجمة والتشغيل عند الحفظ. لتسريع البناء أثناء التطوير يمكن `npm run start -- -b swc`. SWC مترجم سريع، والتفاصيل في درس لاحق من هذا الفصل.

## Mental Model

```text
start       ترجمة ثم تشغيل
start:dev   مراقبة -> ترجمة -> إعادة تشغيل
```

## أبسط مثال

```bash
npm run start:dev
```

## شرح المثال

الأمر يبقى في الطرفية. عند نجاح الإقلاع تقدر أن تطلب الجذر من المتصفح أو `curl http://localhost:3000/`. أوقف العملية بإيقاف الطرفية المعتاد (`Ctrl+C`) قبل تشغيل نسخة ثانية على المنفذ نفسه.

## ماذا يحدث داخليًا؟

السكربت في `package.json` يستدعي CLI. وضع dev يسجّل مراقب ملفات. عند الحفظ يُعاد بناء الناتج ثم عملية Node. إن فشل البناء تبقى رسالة المترجم في الطرفية ولا تعتمد على المتصفح ليشرح خطأ نوع.

## مثال عملي

غيّر النص داخل `getHello` واحفظ. الطلب التالي يجب أن يرى النص الجديد من غير أمر تشغيل ثانٍ. إذا لم يتغير، فأنت تشغّل `start` لا `start:dev`، أو تطلب منفذًا آخر.

## أخطاء شائعة

- تشغيل نسختين على 3000. الثانية تفشل لأن المنفذ محجوز.
- تعديل ملفات في `dist/` بدل `src/`. الناتج يُستبدل في البناء التالي.
- اعتبار مراقب الملفات بديلًا عن إعادة تشغيل عند تغيير `.env` إن لم يكن المحمّل يراقبه. غيّر البيئة وأعد التشغيل إذا لم يلتقطها الوضع.

## متى نستخدمه؟

طوال الدروس العملية.

## متى لا نستخدمه؟

`start:dev` ليس أمر الإنتاج. الإنتاج يشغّل الناتج المبني بأمر بدء إنتاجي كما في درس البناء.

## مقارنة

| أمر | متى |
| --- | --- |
| `npm run start` | تحقق سريع بلا مراقبة |
| `npm run start:dev` | العمل اليومي |
| `npm run start:prod` | بعد بناء، على ناتج `dist` |

## تمارين

### تمرين سهل

أي عنوان تفتحه بعد إقلاع القالب؟

<details><summary>الحل</summary>

`http://localhost:3000/` ما لم يُضبط `PORT`.

</details>

### تمرين متوسط

حفظت الملف والمتصفح ما زال على النص القديم وأنت متأكد أن العملية تعمل. ما أول فحص؟

<details><summary>الحل</summary>

هل الأمر `start:dev`؟ هل الحفظ في `src`؟ هل المتصفح يطلب المنفذ نفسه؟

</details>

### تمرين متقدم

لماذا لا نترك `start:dev` يعمل على الخادم العام؟

<details><summary>الحل</summary>

المراقب وأدوات التطوير ليست عقد التشغيل، وقد تعيد التحميل وتطبع تفاصيل. الإنتاج عملية من ناتج مبني وإعدادات إنتاج.

</details>

## أسئلة مراجعة

- ما الفرق بين `start` و `start:dev`؟
- ما المنفذ الافتراضي؟
- أين تعدّل النص: `src` أم `dist`؟

## الخلاصة

اعمل بـ `start:dev`. اطلب الجذر وتأكد أن Hello World يتغير عندما تغيّر الخدمة.

## ماذا بعد؟

نبني ناتجًا يمكن تشغيله من غير مترجم التطوير.
