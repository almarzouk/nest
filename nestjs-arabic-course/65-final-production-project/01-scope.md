# نطاق المشروع

## الهدف من هذا الدرس

تثبيت ما يُبنى في «رف» خلال هذا الفصل: SaaS لمكتبات مستقلة، يُروى مرحلة مرحلة في الدروس حتى Docker والاختبارات، بلا مستودع يُسلَّم هنا.

## المشكلة التي يحلها

المشروع النهائي ينتفخ إلى متجر كامل: واجهة، تطبيق جوال، ومحرر نصوص. أو يُختصر إلى `nest new` فارغ. الفريق لا يعرف متى يتوقف. هذا الفصل يجمع REST و GraphQL و Prisma و Redis والاختبارات على مسار واحد مكتوب.

## الفكرة ببساطة

المنظمة مكتبة. الشخص مستخدم. العضوية دور. **المشروع** كتاب قيد التجهيز حتى يُنشر على الرف. الاشتراك يحد عدد المشاريع المنشورة. الباقي قنوات: إشعار، تدقيق، مهمة، ويب هوك. كل درس يضيف شريحة ولا يعيد لصق الشرائح السابقة.

## التعريف التقني

داخل النطاق: API على NestJS 12 بـ ESM، Prisma على Postgres، Redis للمهام أو الكاش، عقد REST، سطح GraphQL للقراءة لاحقًا، OpenAPI، Docker، واختبارات. خارج النطاق: تطبيق الواجهة نفسه، تطبيق الجوال، وبناء محرّك دفع غير Stripe. لا مجلد `raf/` في هذه الدورة. الأمثلة مقتطفات تُنسخ عندكم عندما تبنون. Express يبقى الافتراضي ما لم تقيسوا Fastify.


## أبسط مثال

```text
منظمة: دار النيل
عضو: سارة owner
مشروع: «موسم الهجرة» حالة draft
نشر: يمر على الخطة ثم يصبح published
```

## شرح المثال

- المشروع ليس تذكرة إدارة عامة. هو كتاب المكتبة في هذا المنتج.
- «دار النيل» لا ترى مشاريع جارة.
- النشر فعل لاحقًا، لا في درس النطاق.

## ماذا يحدث داخليًا؟

1. تقرأون الدروس بالترتيب. كل واحد يفترض السابق مكتوبًا عندكم.
2. لا تدمجون GraphQL قبل وجود جدول المشاريع.
3. لا تفعّلون Stripe من صفحة نجاح.
4. الاختبار في الدرس 14 يثبت العزل لا كل السطور.
5. إن توقفتكم دورة تعليمية عند درس 05، فالمنتج ناقص لكن العقد واضح.

## مثال عملي

حدود النسخة التي يصفها الفصل:

```text
داخل:  تسجيل، منظمة، عضوية، مشاريع، نشر مشروط، حدث دفع، إشعار دعوة، تدقيق، مهمة غلاف، ويب هوك صادر، إدارة منصة تقرأ عبر المستأجرين، استعلام GraphQL، Swagger، حاوية، اختبار عزل
خارج:  تطبيق React، شحن كتب ورقية، Federation، صومعة قاعدة لكل مكتبة
```

العزل نموذج pool: `organizationId` على كل صف تشغيلي.

## أخطاء شائعة

- إنشاء مستودع في هذا المجلد وظن أن الدرس يطلبه.
- بناء الواجهة قبل عقد 201 وشكل الخطأ.
- تسمية «مشروع» لمهمة داخلية في الكود بدل كتاب المكتبة.
- قفز إلى Docker قبل مسار النشر.

## متى نستخدمه؟

كصفحة عقد قبل أي `schema.prisma`. راجعوها عندما يطلب أحد ميزة خارج القائمة.

## متى لا نستخدمه؟

لا تتحول إلى مواصفة من خمسين صفحة. القائمة أعلاه كافية لهذا الفصل.

## مقارنة

| داخل | خارج |
| --- | --- |
| API والمراحل حتى الاختبار | واجهة المتصفح الكاملة |
| مشروع = كتاب قيد النشر | إدارة مشاريع عامة بلا كتالوج |
| دروس ومقتطفات | مستودع يُولَّد هنا |

</details>

## أسئلة مراجعة

- ماذا يمثّل المشروع في رف؟
- هل هذا الفصل مستودع؟
- أي نموذج عزل؟
- إلى أي درس يمتد النطاق؟

## الخلاصة

رف SaaS مكتبات، والمشروع كتاب قيد النشر، والفصل دروس من النطاق حتى Docker والاختبارات بلا مستودع جاهز. كل درس شريحة.

## ماذا بعد؟

الشريحة الأولى تشغيل: إعداد، قاعدة، ووحدة صحة. الدرس التالي الأساسات.
