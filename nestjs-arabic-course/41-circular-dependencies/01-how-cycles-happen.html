كيف تحدث الدورة

الهدف من هذا الدرس

رؤية الاعتماد الدائري كما يراه Nest: بين صنفين، أو بين وحدتين، أو عبر ملف برميل يعيد التصدير داخل مجلده.

المشكلة التي يحلها

رسالة إقلاع تقول إن الاعتماد غير معرّف، أو أن Nest لا يستطيع حل الدورة، بينما كل ملف يبدو صحيحًا وحده. السبب أن بناء الرسم يحتاج الرمزين معًا قبل أن يكتمل أي منهما، أو أن index.ts يسحب الوحدة وهي ما زالت تُقيَّم.

الفكرة ببساطة

دورة بين Providers: A يحقن B و B يحقن A في الـ constructor. دورة بين Modules: كل وحدة تضع الأخرى في imports. دورة ملفات: برميل cats/index.ts يصدّر المتحكم والخدمة، والملف داخل المجلد يستورد من البرميل فيعود إلى نفسه أثناء التحميل. التوثيق يطلب تجنب البراميل لأصناف الوحدات والمزودات، وخصوصًا استيراد البرميل من ملف جاره.

التعريف التقني

صفحة Circular dependency: الدورة عندما يحتاج صنف A الصنف B والعكس. تحدث في Nest بين المزودات وبين الوحدات. الإطار يحتاج metadata الطرف الآخر أثناء تحليل الـ constructor. إن كان الصنف لم يُهيأ بعد لأن تحميله ينتظرك، يصل الاعتماد فارغًا.

forwardRef يؤجل قراءة الصنف إلى دالة، وهذا الدرس التالي بعد أن ترى الشكل الخام. ModuleRef بديل على طرف واحد، ويُشرح مع إعادة الرسم.

تحذير التوثيق: ترتيب الإنشاء غير محدد، فلا تبنِ منطقًا يعتمد على أي constructor يعمل أولًا. دورة مع Scope.REQUEST قد تنتج اعتمادًا undefined.

Mental Model

تحميل الملف أ ينتظر الصنف ب
تحميل الملف ب ينتظر الصنف أ
الحاوية ترى رمزًا لم يكتمل -> فشل حل أو undefined

index.ts يصدّر الخدمة
الخدمة تستورد من index.ts
التحميل يدور قبل أن يُغلق التصدير

الدورة قد تكون في الرسم المنطقي أو في ترتيب ملفات TypeScript فقط. الثانية تختفي بتغيير سطر الاستيراد، والأولى تحتاج حدودًا جديدة.

أبسط مثال

import { Injectable } from '@nestjs/common';
import { OrdersService } from './orders.service.js';

@Injectable()
export class BillingService {
  constructor(private readonly orders: OrdersService) {}
}

import { Injectable } from '@nestjs/common';
import { BillingService } from './billing.service.js';

@Injectable()
export class OrdersService {
  constructor(private readonly billing: BillingService) {}
}

كل ملف قانوني وحده. معًا يشكلان دورة مزودات. الإقلاع لا يضمن أي طرف يُبنى أولًا.

شرح المثال

BillingService يحتاج نسخة OrdersService قبل أن يُكمل بناءه، والعكس صحيح. الحاوية لا تجد ترتيبًا سفليًا كما في الرسم الخالي من الدورات. إن أضفت Scope.REQUEST على أحدهما زاد احتمال أن ترى الطرف الآخر undefined وقت البناء، وهذا تحذير موثق لا حالة نادرة تُهمل.

ماذا يحدث داخليًا؟

  1. import يقيّم الملفات. مع ESM ودورة ملفات قد يكون الربط الحي ما زال في طور التهيئة.
  2. المزخرفات تكتب metadata أنواع المعاملات.
  3. إن كان الرمز undefined لحظة قراءة النوع، تُحفظ metadata ناقصة.
  4. عند إنشاء الرسم يرمي Nest أو يترك حقنًا فارغًا.
  5. دورة الوحدات مشابهة على مستوى imports: كل وحدة تنتظر تهيئة الأخرى.
  6. البرميل يزيد الخطوة 1 حتى لو كان الرسم المنطقي شجرة.

مثال عملي

export { BooksService } from './books.service.js';
export { BooksModule } from './books.module.js';

وداخل books.service.ts سطر import { BooksModule } from './index.js' يعود إلى البرميل الذي ينتظر الخدمة. التوثيق: cats/cats.controller لا يستورد مجلد cats ليحصل على cats.service. استورد ./books.service.js مباشرة. إن اختفت الرسالة بعد هذا التغيير فالدورة كانت في الملفات. إن بقيت فالدورة في الـ constructor أو في imports.

أخطاء شائعة

  • زيادة forwardRef قبل معرفة إن كان البرميل هو السبب.
  • دورة وحدات لأن كل ميزة تستورد الأخرى بدل طرف مشترك صغير.
  • الاعتماد على ترتيب البناء لملء حقل.
  • خلط رسالة ESM عن تصدير حي مع رسالة Nest عن حل الاعتماد. اقرأ الاثنتين.
  • إخفاء الدورة وراء new OtherService() داخل الدالة، فتفقد الحقن والاختبار.

متى نستخدمه؟

عند فشل الإقلاع بسبب اعتماد فارغ أو تحذير دورة. ارسم السهمين على ورقة قبل أي مسكن.

متى لا نستخدمه؟

لا تفتح forwardRef لأن اختبارًا واحدًا فشل في ترتيب beforeEach. أصلح الاستيراد أو الحدود أولًا.

تمرين سهل

ما تعريف الدورة بين صنفين؟

الحل

كل واحد يحتاج الآخر. في Nest تكون بين مزودات أو بين وحدات.

تمرين متوسط

لماذا يمنع التوثيق أن يستورد cats.controller مجلد cats؟

الحل

البرميل يصدّر المتحكم والخدمة، والاستيراد من داخل المجلد نفسه يعيد التحميل إلى البرميل قبل اكتمال التصدير، فتنشأ دورة ملفات.

تمرين متقدم

دورة مزودات وأحد الطرفين Scope.REQUEST. ماذا يحذّر التوثيق بالإضافة إلى فشل الترتيب؟

الحل

قد يصل الاعتماد undefined. ترتيب الإنشاء أصلًا غير محدد، ونطاق الطلب يزيد هشاشة الدورة.

أسئلة مراجعة

  • ما أنواع الدورات الثلاثة التي تبحث عنها؟
  • لماذا ترتيب الـ constructor ليس عقدًا؟
  • ماذا تغيّر في الاستيراد قبل forwardRef؟

الخلاصة

الدورة إما رسم حقن دائري أو تحميل ملفات دائري. ارسمها، وأزل البرميل الداخلي، ثم قرر إن كانت الحدود نفسها هي العيب.

ماذا بعد؟

متى تكون الدورة مشكلة تصميم لا مجرد سطر ناقص.
