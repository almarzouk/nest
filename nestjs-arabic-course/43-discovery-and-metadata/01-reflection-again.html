Reflection مرة أخرى

الهدف من هذا الدرس

تذكر أن المزخرفات تلصق بيانات على الصنف أو الدالة وقت تحميل الملف، وأن Nest يقرأها لاحقًا، قبل أن تسمي Reflector أداة تلك القراءة.

المشكلة التي يحلها

كتابة if (role === 'admin') داخل كل متحكم تكرر السياسة وتخفيها عن الحارس. لصق السياسة على الدالة مرة، ثم قراءتها من مكان واحد، يحتاج مخزنًا يعيش بعد الترجمة. TypeScript يمحو الأنواع. reflect-metadata و SetMetadata يبقيان قيمًا وقت التشغيل. هذا الدرس يثبت المخزن. الدرس التالي هو الصنف الذي يقرأه Nest.

الفكرة ببساطة

عند تقييم الملف تشغّل المزخرفات دوالًا. تلك الدوال تستدعي Reflect.defineMetadata(key, value, target, property?). المفتاح سلسلة أو رمز، والقيمة ما تشاء، والهدف الصنف أو كائن النموذج للدالة. لاحقًا Reflect.getMetadata يعيد القيمة. Nest يغلّف هذا المسار حتى لا تنثر مفاتيح نصية في الحراس.

التعريف التقني

مشروع Nest يفعّل emitDecoratorMetadata غالبًا، فيُخزن تصميم المعاملات تحت مفاتيح مثل design:paramtypes. لذلك يعرف الإطار نوع constructor(private books: BooksService) ويحقن الرمز. هذا انعكاس للأنواع التي بقيت كقيم.

SetMetadata من @nestjs/common مخزن ثانٍ لمفاتيحك أنت:

import { SetMetadata } from '@nestjs/common';

export const ROLES_KEY = 'roles';
export const Roles = (...roles: string[]) => SetMetadata(ROLES_KEY, roles);

@Roles('admin') فوق الدالة يضع المصفوفة على الدالة لا على الصنف، إلا إذا وضعت المزخرف على الصنف. المفتاح الثابت ROLES_KEY يمنع اختلاف الإملاء بين الكاتب والقارئ.

الواجهة interface Roles لا تصلح رمز حقن ولا مفتاح انعكاس لأنها تُمحى. الرمز الذي يبقى هو الدالة أو Symbol أو الصنف.

ترتيب التقييم: المزخرفات السفلية قد تُنفذ قبل العلوية حسب لغة المزخرفات. لا تعتمد على ترتيب جانبي لقراءة metadata أثناء تعريف المزخرف نفسه. اقرأها لاحقًا في الحارس عندما يكون الصنف مكتملًا.

Mental Model

تحميل الملف
  -> @Roles يكتب المفتاح roles على الدالة
  -> design:paramtypes على الصنف للحقن
الإقلاع والطلب
  -> قارئ واحد يسأل المفتاح

اللصق عند التحميل. القرار عند الطلب.

أبسط مثال

import { SetMetadata } from '@nestjs/common';

export const IS_PUBLIC_KEY = 'isPublic';
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);

import { Controller, Get } from '@nestjs/common';
import { Public } from './public.decorator.js';

@Controller('health')
export class HealthController {
  @Public()
  @Get()
  live(): { ok: true } {
    return { ok: true };
  }
}

لا شرط داخل live. العلم على الدالة. الحارس الذي ستقرأه بـ Reflector يرى العلم ويسمح بالمسار.

شرح المثال

Public مصنع مزخرف بلا وسائط يعيد نداء SetMetadata. المفتاح 'isPublic' والقيمة true. وضعه على الدالة يعني أن بقية دوال المتحكم تبقى محمية إن كان الحارس يفضّل الدالة على الصنف. هذا الاتفاق يُكتب في القارئ لا في المزخرف وحده.

ماذا يحدث داخليًا؟

  1. Node يقيّم الملف فتستدعي @Public() الدالة.
  2. SetMetadata يسجل metadata على الهدف.
  3. جدول Nest للمسارات يربط GET /health بالدالة.
  4. عند الطلب، الحارس يحصل على الدالة والصنف من السياق ويسأل المفتاح.
  5. غياب المفتاح ليس قيمة false بالضرورة. القارئ يقرر الافتراض: مغلق حتى يُلصق العلم.
  6. design:paramtypes مسار آخر خاص بالحقن، لا تكتب فيه أدوارك.

مثال عملي

مفتاح مهلة خاص بمسار التصدير:

import { SetMetadata } from '@nestjs/common';

export const TIMEOUT_MS = 'timeoutMs';
export const TimeoutMs = (ms: number) => SetMetadata(TIMEOUT_MS, ms);

المعترض يقرأ الرقم ويقطع العمل إن طال. الدالة التي بلا مزخرف تستعمل مهلة التطبيق الافتراضية لأن getMetadata يعيد undefined. لا تخزن المهلة على حقل Singleton يتغير مع كل طلب.

أخطاء شائعة

  • مفتاحان نصيان مختلفان لنفس السياسة: 'role' و 'roles'.
  • توقع بقاء interface كمفتاح.
  • قراءة metadata أثناء تنفيذ المزخرف قبل أن تُلصق مزخرفات أخرى.
  • وضع السر في metadata. القيمة ظاهرة لمن يملك الصنف في العملية.
  • خلط design:paramtypes مع مفاتيح العمل.

متى نستخدمه؟

سياسة أو رقم أو علم يتبع الدالة أو الصنف ويُقرأ من حارس أو معترض واحد.

متى لا نستخدمه؟

بيانات الطلب الحالي. تلك على request أو وسيط. إعداد البيئة مكانه ConfigService لا مزخرف على المتحكم.

مقارنة

المخزن متى يُكتب مثال
design:paramtypes من المترجم للمزخرفات أنواع الـ constructor
SetMetadata مزخرفك أدوار، علم عام، مهلة
حقل على الخدمة وقت التشغيل حالة تتغير، وليست لصقًا على الدالة

تمارين

تمرين سهل

متى تُكتب metadata نسبة إلى أول طلب HTTP؟

الحل

عند تحميل الملف وتشغيل المزخرف، أي أثناء الإقلاع وقبل الطلب.

تمرين متوسط

لماذا ROLES_KEY ثابت مصدَّر؟

الحل

حتى يستعمل الكاتب والقارئ السلسلة نفسها. اختلاف حرف يمنع الحارس من رؤية القيمة.

تمرين متقدم

لماذا لا يصلح interface User مفتاح SetMetadata؟

الحل

الواجهات تُمحى في الترجمة ولا توجد قيمة وقت التشغيل تُستخدم كمفتاح.

أسئلة مراجعة

  • ماذا يبقى بعد محو الأنواع؟
  • على أي هدف يلصق مزخرف فوق الدالة؟
  • ما مفتاح الحقن الذي لا تضع فيه أدوارك؟

الخلاصة

الانعكاس يلصق قيمًا على الصنف أو الدالة عند التحميل. SetMetadata لمفاتيحك، و design:paramtypes للحقن. القراءة تأتي من أداة واحدة في الدرس التالي.

ماذا بعد؟

Reflector: قراءة المفتاح من الدالة والصنف بقواعد التغليب والدمج.
