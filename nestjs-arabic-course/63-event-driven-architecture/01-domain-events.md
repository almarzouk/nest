# Domain Events

## الهدف من هذا الدرس

تسمية ما حدث داخل نموذج مكتبة رف بعد ما نجح، مثل «نُشر الكتاب»، كحدث يسمعه كود داخل نفس الحد، لا كنداء مباشر لكل خدمة.

## المشكلة التي يحلها

`publish()` يستدعي البريد والفهرس والتدقيق والكاش بالاسم. إضافة مستمع رابع تعدّل دالة النشر. الاختبار لا يستطيع إثبات أن النشر تم من غير تشغيل البريد.

## الفكرة ببساطة

حدث النطاق جملة ماضٍ داخل النموذج: `BookPublished` فيه معرّفات. يُطلق بعد ما تصبح الحالة صحيحة في الذاكرة أو في المعاملة، والمستمعون داخل نفس التطبيق يتفاعلون. الحدث ليس رسالة إلى شريك خارجي. تلك أحداث تكامل في الدرس التالي.

## التعريف التقني

الصنف يحمل `organizationId` و `bookId` و `occurredAt` بلا كيان Prisma كامل. `@nestjs/event-emitter` يقدر أن ينقل هذا داخل العملية بـ `emit` و `@OnEvent`، وهو مناسب لمستمعين في نفس الـ deploy. الإطلاق بعد نجاح قاعدة «منشور» لا قبلها، وإلا سمع المستمع حدثًا لم يُلتزم. فشل المستمع لا يعيد الكتاب مسودة إن كان الأثر الجانبي خارج القاعدة؛ لذلك المستمع الذي يجب ألا يضيع يحتاج نمطًا أقوى لاحقًا. لا تسمّوا `EventEmitter` ناقلًا بين الخدمات.

## Mental Model

```text
BooksService تغيّر الحالة
ثم BookPublished { organizationId, bookId }
مستمع داخل العملية: تدقيق، إشعار
الشريك الخارجي ليس مشتركًا هنا
```

## أبسط مثال

```ts
export class BookPublished {
  constructor(
    readonly organizationId: string,
    readonly bookId: string,
    readonly occurredAt = new Date(),
  ) {}
}
```

## شرح المثال

- الاسم ماضٍ. ليس `PublishBook` أمرًا.
- المعرّفات تكفي والمستمع يحمّل ما يحتاج داخل نفس المستأجر.
- لا حقل `stripeSecret` ولا جسم الطلب.

## ماذا يحدث داخليًا؟

1. الخدمة تتحقق من الخطة والعضوية والمستأجر.
2. تكتب `published` في المعاملة.
3. بعد النجاح تبني `BookPublished`.
4. المستمعون المحليون يعملون. إن كانوا داخل نفس المعاملة فهم جزء من الاتساق القوي لذلك الأثر.
5. من هم خارج المعاملة قد يفشلون والكتاب يبقى منشورًا. هذا حد الحدث الداخلي.

## مثال عملي

```ts
import { Injectable } from '@nestjs/common';
import { EventEmitter2 } from '@nestjs/event-emitter';
import { BookPublished } from './book-published.js';

@Injectable()
export class BooksService {
  constructor(private readonly events: EventEmitter2) {}

  async publish(organizationId: string, bookId: string) {
    await this.markPublished(organizationId, bookId);
    this.events.emit('book.published', new BookPublished(organizationId, bookId));
  }
}
```

`markPublished` حيث القيد `organizationId`. `emit` بعد الكتابة. مستمع `@OnEvent('book.published')` يدرج إشعارًا. لا تستورد الخدمة صف البريد.

## أخطاء شائعة

- إطلاق الحدث قبل `UPDATE` ثم فشل الكتابة.
- حمولة فيها الكيان كاملًا فيمسك المستمع نسخة قديمة ضخمة.
- اعتبار `@OnEvent` تسليمًا إلى شريك HTTP.
- مستمع يغيّر حالة الكتاب بصمت فيصعب تتبع من نشر.

## متى نستخدمه؟

عندما يتبع أثرًا ناجحًا أكثر من مستمع داخل نفس الخدمة أو نفس العملية، وتريدون إضافة مستمع بلا تعديل سلسلة الاستيراد.

## متى لا نستخدمه؟

لأمر لم يحدث بعد («انشر من فضلك»). ذلك استدعاء دالة. ولا لحدث يجب أن يصل خدمة أخرى حتى بعد سقوط العملية؛ ذلك تكامل وصندوق صادر.

## مقارنة

| | أمر | حدث نطاق |
| --- | --- | --- |
| الزمن | طلب | وقع |
| الاتجاه | من يستدعي يعرف الهدف | الناشر لا يستورد كل المستمعين |
| الحدود | داخل النموذج | داخل النموذج أو العملية |

## تمارين

### تمرين سهل

هل `BookPublished` يُطلق عندما يرفض الحارس الموظف؟

<details>
<summary>الحل</summary>

لا. الرفض يعني أن النشر لم يحدث. الحدث بعد الكتابة الناجحة فقط.

</details>

### تمرين متوسط

لماذا المعرّف لا الكائن كاملًا؟

<details>
<summary>الحل</summary>

حتى يحمّل المستمع الحالة الحالية من القاعدة. الكائن المنسوخ قد يخالف صفًا تغيّر، ويكبر حجم الذاكرة.

</details>

### تمرين متقدم

المستمع أرسل بريدًا ثم رمى. هل تعيد `publish` الكتاب إلى مسودة؟

<details>
<summary>الحل</summary>

لا في هذا التصميم. الكتاب ملتزم. فشل البريد إشعار `failed` كما في معمارية SaaS. إن وجب أن يموت الاثنان معًا فهما في معاملة واحدة لا عبر `emit` بعد الالتزام.

</details>

## أسئلة مراجعة

- متى يُطلق حدث النطاق؟
- ماذا يحمل؟
- لماذا ليس أمر `PublishBook`؟
- هل `@OnEvent` يعبر إلى شريك؟

## الخلاصة

حدث النطاق حقيقة داخل النموذج بعد نجاح القاعدة: معرّفات واسم ماضٍ. المستمعون المحليون يتفاعلون. سقوط المستمع الجانبي لا يلغي النشر، والتسليم الخارجي ليس هذا الصنف.

## ماذا بعد؟

شريك المخزون خارج العملية يحتاج حدثًا بعقد أوضح. الدرس التالي أحداث التكامل.
