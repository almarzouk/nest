# ماذا بعد أدوات العمل؟

رف تُنشأ بـ `nest new` على ESM و Vitest و oxlint و Prettier، وتُجمع في مساحة بـ Rspack، وتُترجم في التطوير بـ `npm run start -- -b swc` مع فحص الأنواع، وتُستكشف بـ REPL و Devtools، وتُشغَّل مهمة بلا منفذ بسياق مستقل أو `nest-commander`.

ما تبقى ميزات منصة تُضاف عند الحاجة: ترجمة الواجهة، والبريد، وتخزين الملفات، ودفق الأحداث، و serverless، والتطبيق الهجين.
