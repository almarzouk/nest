37 — دفع وهمي بلا تكرار

المستوى: متقدم
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new checkout-idempotency

ماذا تبني

POST /payments يحمل ترويسة Idempotency-Key. إعادة نفس المفتاح تعيد نفس النتيجة ولا تخصم مرتين.

لماذا هذا المشروع الآن

الزبون يعيد المحاولة عند انقطاع الشبكة. من غير مفتاح يصبح له طلبان.

ماذا ستتعلم

  • مفتاح تكرار
  • قيد فريد
  • إعادة نفس الرد

ما الذي لن تبنيه في هذا المشروع

  • Stripe حقيقي. ذلك مشروع لاحق.
  • استرداد

قبل أن تبدأ

الطلب والمخزون.

من الدورة: 66-reliability.

قواعد العمل

  • المفتاح مطلوب على الدفع.
  • نفس المفتاح ونفس الجسم يعيد الرد الأول.
  • نفس المفتاح وجسم مختلف 409.
  • الخصم يحدث مرة واحدة.
  • المفتاح يُخزَّن مع هاش الجسم لا مع أسرار بطاقة. لا بطاقة هنا أصلًا. الدفع وهمي ينجح دائمًا بعد الخصم.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /payments 201 أول مرة
POST /payments 200 إعادة نفس المفتاح

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new checkout-idempotency. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. جدول idempotency فيه المفتاح وهاش الجسم ومعرّف الدفع.
  2. ال قيد الفريد على المفتاح.
  3. لف الخصم وإنشاء الدفع في معاملة واحدة مع صف المفتاح.

شكل مقترح

src/payments/payments.service.ts
prisma/schema.prisma

أصغر قطعة تبدأ منها

const existing = await this.findKey(key);
if (existing && existing.requestHash !== hash) {
  throw new ConflictException("idempotency key reuse");
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • مفتاح في الجسم يسهل تزويره من غير اتفاق. الترويسة هي العقد هنا.
  • إنشاء دفعة جديدة عند كل إعادة.
  • نسيان هاش الجسم فيُعاد رد عملية أخرى.

ينتهي المشروع عندما

  • إعادتان بمفتاح واحد تخصم مرة.
  • جسم مختلف بنفس المفتاح 409.
  • من غير الترويسة 400.
