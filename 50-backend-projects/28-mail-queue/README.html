28 — طابور رسائل الترحيب

المستوى: متوسط
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new mail-queue

ماذا تبني

التسجيل يرجع فورًا. رسالة الترحيب تُوضع في طابور. العامل يحاول ثلاث مرات ثم يتوقف. لا يُمرَّر كائن المستخدم كاملًا إلى الوظيفة.

لماذا هذا المشروع الآن

العمل البطيء يخرج من دورة POST. Bull في وضع الصيانة، والمسار هنا BullMQ.

ماذا ستتعلم

  • @nestjs/bullmq
  • معرّف في الحمولة
  • إعادة المحاولة

ما الذي لن تبنيه في هذا المشروع

  • SMTP حقيقي إلزامي. العامل قد يسجّل أنه أرسل إلى مزود وهمي.
  • حملات تسويق

قبل أن تبدأ

الحسابات، و Redis محلي للمشروع.

من الدورة: 34-queues.

قواعد العمل

  • الرد 201 قبل أن يفرغ الطابور.
  • الحمولة userId لا password ولا الكيان.
  • ثلاث محاولات.
  • فشل التسجيل لا يضيف وظيفة.
  • لا تستخدم @nestjs/bull في المشروع الجديد.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /auth/register 201 ينشئ الحساب ويضيف الوظيفة
GET /admin/mail-jobs/:id 200 حالة الوظيفة للتعلم

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new mail-queue. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. BullModule.forRoot بالاتصال، ثم registerQueue بالاسم.
  2. بعد حفظ المستخدم أضف الوظيفة.
  3. العامل يحمّل المستخدم من المعرّف. إن حُذف المستخدم تُغلق الوظيفة بهدوء موثّق.

شكل مقترح

src/mail/mail.processor.ts
src/auth/auth.service.ts

أصغر قطعة تبدأ منها

await this.mailQueue.add("welcome", { userId: user.id }, {
  attempts: 3,
  backoff: { type: "exponential", delay: 1000 },
});

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • تمرير passwordHash داخل الوظيفة.
  • انتظار العامل قبل رد 201.
  • نسخ مثال Bull القديم على حزمة BullMQ.

ينتهي المشروع عندما

  • التسجيل لا ينتظر الإرسال.
  • الحمولة معرف فقط.
  • إيقاف Redis يظهر خطأ اتصال مفهوم لا نجاحًا كاذبًا.

تمديد بعد الانتهاء

أضف وظيفة ثانية لتغيير البريد من غير خلط الاسمين.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 28» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
