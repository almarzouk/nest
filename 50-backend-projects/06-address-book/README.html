06 — دفتر عناوين

المستوى: مبتدئ
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new address-book

ماذا تبني

جهات اتصال بالاسم والجوال والبريد. الجوال لا يتكرر. البحث ?q= يطابق الاسم.

لماذا هذا المشروع الآن

أول 409 في المسار. التفرد قاعدة عمل لا قيد واجهة.

ماذا ستتعلم

  • ConflictException
  • الاستعلام للبحث
  • حذف لا يحرر التفرد خطأً

ما الذي لن تبنيه في هذا المشروع

  • استيراد CSV
  • حسابات
  • تحقق دولي معقد لرقم الهاتف

قبل أن تبدأ

العداد.

من الدورة: 15-exception-filters.

قواعد العمل

  • phone فريد بعد حذف المسافات.
  • البريد يُخزَّن بحروف صغيرة.
  • تكرار الجوال 409 حتى لو اختلف الاسم.
  • بحث بلا نتائج 200 و [].

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /contacts 201 ينشئ أو 409
GET /contacts?q=sara 200 يطابق جزءًا من الاسم
DELETE /contacts/:id 204 يحرر الجوال لإعادة الاستخدام

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new address-book. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. طبّع الجوال بدالة تزيل المسافات قبل المقارنة.
  2. ابحث بالتضمين على الاسم بعد lower case.
  3. بعد الحذف، أعد إنشاء الجهة نفسها وتوقع 201.

شكل مقترح

src/contacts/normalize.ts
src/contacts/contacts.service.ts

أصغر قطعة تبدأ منها

export function normalizePhone(input: string) {
  return input.replace(/\s+/g, "");
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • مقارنة الجوال كما كتبه المستخدم مع مسافات.
  • إرجاع 404 عند البحث الفاشل.
  • تعديل الجهة من غير إعادة فحص التفرد.

ينتهي المشروع عندما

  • نفس الرقم مرتين يعطي 409.
  • بعد الحذف يُقبل الرقم.
  • q فارغ يعيد الكل.

تمديد بعد الانتهاء

أضف PATCH للبريد مع إبقاء تفرد الجوال.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 6» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
