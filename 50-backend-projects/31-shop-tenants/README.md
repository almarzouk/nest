# 31 — ملاحظات لكل متجر

**المستوى:** متقدم  
**النوع:** Backend فقط  
**الأمر الذي تبدأ منه:** `nest new shop-tenants`

## ماذا تبني

كل طلب يحمل x-tenant-id. الملاحظات تُعزل. المعرّف لا يُؤخذ من الجسم.

## لماذا هذا المشروع الآن

أول عزل قبل الفوترة والمنظمات. الخطأ هنا خلط بيانات زبونين.

## ماذا ستتعلم

- مصدر المستأجر
- كل استعلام مقيّد
- 400 عند غياب الترويسة

## ما الذي لن تبنيه في هذا المشروع

- قاعدة لكل زبون
- نطاقات DNS
- فوترة

## قبل أن تبدأ

الملاحظات. أعد الفكرة مع العزل.

من الدورة: [59-multi-tenancy](../../nestjs-arabic-course/59-multi-tenancy/README.md).

## قواعد العمل

- غياب الترويسة 400.
- جسم فيه tenantId 400.
- ملاحظة متجر لا تظهر لمتجر آخر حتى لو عُرف id. الرد 404 لا بيانات الغير.
- قائمة كل المتاجر بلا قيد غير موجودة.

## عقد HTTP

| الطريقة | المسار | الرمز | ماذا يفعل |
| --- | --- | --- | --- |
| `POST` | `/notes` | 201 | تُحفظ تحت الترويسة |
| `GET` | `/notes/:id` | 200 | فقط إن طابقت الترويسة |

القائمة الفارغة `200` بجسم `[]` أو غلاف بيانات، لا `404`. الإنشاء `201`. الغائب `404`. التعارض `409`. الدخل الرديء `400`.

## من الصفر

1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ `nest new shop-tenants`. اختر ESM عندما يسأل Nest CLI.
2. لا تنسخ `node_modules` إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
3. أبقِ `AppModule` جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل `main.ts`.
4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

## خطوات البناء

1. استخرج المستأجر في حارس أو وسيط مرة واحدة.
2. الخدمة تأخذ tenantId وسيطًا إلزاميًا لا تقرأه من جسم.
3. اختبر نفس id بترويستين.

## شكل مقترح

```text
src/tenant/tenant.guard.ts
src/notes/notes.service.ts
```

## أصغر قطعة تبدأ منها

```ts
findOne(tenantId: string, id: string) {
  const note = this.notes.find((item) => item.id === id && item.tenantId === tenantId);
  if (!note) throw new NotFoundException();
  return note;
}
```

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

## أخطاء تظهر هنا كثيرًا

- قراءة tenant من body.
- نسيان القيد في مسار واحد.
- إرجاع 403 يكشف أن الملاحظة موجودة لغيرك. استخدم 404 هنا.

## ينتهي المشروع عندما

- ترويستان لا تتقاسمان قائمة.
- الجسم الذي يحمل tenantId يُرفض.
- مسار بلا قيد غير موجود في الكود.

## تمديد بعد الانتهاء

انقل المعرّف إلى مطالبة في الرمز عندما تدمج الحسابات.

## كيف نبنيه معًا

عندما تقول «ابدأ المشروع 31» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
