# 22 — الملف الحالي

**المستوى:** متوسط  
**النوع:** Backend فقط  
**الأمر الذي تبدأ منه:** `nest new profile`

## ماذا تبني

مسار /me يقرأ صاحب الرمز. التعديل يمس الاسم فقط. التجزئة لا تخرج في أي رد.

## لماذا هذا المشروع الآن

بعد إصدار الرمز تحتاج أن تحمله على الطلب من غير أن يثق المتحكم بالجسم.

## ماذا ستتعلم

- حارس يقرأ Authorization
- مستخدم على الطلب
- @Exclude أو DTO خرج

## ما الذي لن تبنيه في هذا المشروع

- أدوار
- صورة
- تغيير البريد

## قبل أن تبدأ

الحسابات. أعد بناء التسجيل والدخول بشكل مبسط أو استخرج الوحدة بوعي لا بنسخ أعمى.

من الدورة: [25-serialization](../../nestjs-arabic-course/25-serialization/README.md).

## قواعد العمل

- Bearer هو الرمز الذي أصدرته.
- غيابه أو بطلانه 401.
- PATCH /me يقبل displayName فقط.
- محاولة إرسال passwordHash في الجسم 400.
- لا مسار /users/:id يرى الغرباء في هذا المشروع.

## عقد HTTP

| الطريقة | المسار | الرمز | ماذا يفعل |
| --- | --- | --- | --- |
| `GET` | `/me` | 200 | صاحب الرمز |
| `PATCH` | `/me` | 200 | يعدّل الاسم الظاهر |

القائمة الفارغة `200` بجسم `[]` أو غلاف بيانات، لا `404`. الإنشاء `201`. الغائب `404`. التعارض `409`. الدخل الرديء `400`.

## من الصفر

1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ `nest new profile`. اختر ESM عندما يسأل Nest CLI.
2. لا تنسخ `node_modules` إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
3. أبقِ `AppModule` جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل `main.ts`.
4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

## خطوات البناء

1. الحارس يضع user على الطلب أو يرمي 401.
2. زينة معامل أو ExecutionContext تقرأ المستخدم. لا تقرأ الرمز داخل الخدمة كل مرة.
3. DTO الخرج فيه id و email و displayName.

## شكل مقترح

```text
src/auth/session.guard.ts
src/profile/profile.controller.ts
src/profile/profile-response.ts
```

## أصغر قطعة تبدأ منها

```ts
@Get("me")
me(@CurrentUser() user: { id: string; email: string; displayName: string }) {
  return user;
}
```

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

## أخطاء تظهر هنا كثيرًا

- أخذ userId من الجسم.
- إرجاع كيان المستخدم كاملًا وفيه التجزئة.
- حارس على /auth/login فيصير الدخول مستحيلًا.

## ينتهي المشروع عندما

- من غير ترويسة 401.
- الرد بلا تجزئة.
- مستخدمان لا يرى أحدهما ملف الآخر لأن المسار /me فقط.

## تمديد بعد الانتهاء

أضف تغيير كلمة المرور بطلب الكلمة الحالية.

## كيف نبنيه معًا

عندما تقول «ابدأ المشروع 22» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
