03 — لوحة مهام

المستوى: مبتدئ
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new task-board

ماذا تبني

مهام بثلاث حالات فقط: todo و doing و done. النقل بينهما مقيد، والفلتر يأتي من الاستعلام.

لماذا هذا المشروع الآن

ليس كل حقل نصًا حرًا. الحالة عقد، والاستعلام يضيّق القائمة ولا يغيّر هوية المورد.

ماذا ستتعلم

  • @Query
  • رفض قيمة خارج المجموعة
  • PATCH يغيّر الحالة لا ينشئ مهمة

ما الذي لن تبنيه في هذا المشروع

  • مستخدمون
  • لوحات متعددة
  • تواريخ استحقاق مع منطقة زمنية

قبل أن تبدأ

ملاحظات الذاكرة.

من الدورة: 05-controllers.

قواعد العمل

  • الحالات الثلاث فقط.
  • من done لا رجوع إلى todo. الرجوع إلى doing مسموح.
  • فلتر status غير المعروف 400 لا قائمة فارغة.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /tasks 201 ينشئ بحالة todo
GET /tasks?status=doing 200 يفلتر أو يعيد الكل
PATCH /tasks/:id/status 200 ينقل الحالة إن جاز

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new task-board. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. عرّف اتحادًا نصيًا للحالات في ملف types.
  2. دالة canMove(from, to) ترفض done إلى todo.
  3. الاستعلام يُقارن بعد التحقق لا بثقة TypeScript وحدها.

شكل مقترح

src/tasks/task-status.ts
src/tasks/tasks.service.ts
src/tasks/tasks.controller.ts

أصغر قطعة تبدأ منها

const STATUSES = ["todo", "doing", "done"] as const;
type TaskStatus = (typeof STATUSES)[number];

export function parseStatus(value: string): TaskStatus {
  if (STATUSES.includes(value as TaskStatus)) return value as TaskStatus;
  throw new Error("bad status");
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • قبول status: "archived" لأن النوع في الملف لا يصل إلى JSON.
  • استخدام مسار /tasks/updateStatus.
  • اعتبار ?status= جزءًا من اسم مورد جديد.

ينتهي المشروع عندما

  • النقل الممنوع يرجع 409.
  • فلتر خاطئ يرجع 400.
  • قائمة بلا مهام ترجع 200 و [].
