24 — غلاف المقال

المستوى: متوسط
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new cover-upload

ماذا تبني

رفع صورة غلاف لمقال. النوع والحجم يُفحصان. الملف يُخزَّن باسم مولَّد لا باسم المستخدم. الرد بيانات لا بايتات.

لماذا هذا المشروع الآن

أول مدخل ليس JSON. الحدود هنا تحمي القرص.

ماذا ستتعلم

  • FileInterceptor
  • mime و size
  • اسم تخزين آمن

ما الذي لن تبنيه في هذا المشروع

  • S3
  • معالجة صور
  • CDN

قبل أن تبدأ

الأدوار. اربط الرفع بالمحرر صاحب المقال أو بالمدير.

من الدورة: 27-file-upload.

قواعد العمل

  • image/jpeg و image/png فقط.
  • السقف 1 ميغابايت.
  • اسم الملف على القرص uuid لا originalname.
  • المقال الغائب 404 ولا يُكتب ملف.
  • احذف الملف القديم عند الاستبدال أو وثّق أنك تتركه. اختر الحذف.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /articles/:id/cover 201 يرفع ويحفظ المسار الداخلي
GET /articles/:id 200 يتضمن coverUrl نسبيًا

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new cover-upload. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. ارفض قبل الكتابة إن أمكن، وإن كُتب ملف مرفوض فاحذفه.
  2. لا تضع مجلد الرفع تحت مسار عام بلا قرار. في هذا المشروع الرد يعيد معرف الملف ومسارًا يخدمه Nest بحد واضح، أو أرجئ الخدمة العامة إلى ملاحظة في التمديد.
  3. اختبر ملفًا نصيًا وتوقع 400.

شكل مقترح

src/covers/covers.controller.ts
uploads/  (غير متابع في git)

أصغر قطعة تبدأ منها

@Post(":id/cover")
@UseInterceptors(FileInterceptor("file", { limits: { fileSize: 1_000_000 } }))
upload(@Param("id") id: string, @UploadedFile() file?: Express.Multer.File) {
  return this.covers.save(id, file);
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • الثقة بامتداد الاسم.
  • حفظ originalname في المسار فيصير ../../ ممكنًا.
  • إرجاع الملف داخل JSON بترميز ضخم.

ينتهي المشروع عندما

  • نص عادي يُرفض.
  • صورتان متتاليتان لا تتركان الأولى على القرص.
  • مقال غير موجود لا يترك ملفًا.

تمديد بعد الانتهاء

أضف حذف الغلاف من غير حذف المقال.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 24» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
