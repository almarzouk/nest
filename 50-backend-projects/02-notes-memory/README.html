02 — ملاحظات في الذاكرة

المستوى: مبتدئ
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new notes-memory

ماذا تبني

دفتر ملاحظات يعيش داخل مصفوفة في Service. إنشاء، وعرض، وتعديل العنوان، وحذف. بعد إعادة التشغيل الدفتر فارغ، وهذا مقصود.

لماذا هذا المشروع الآن

هنا تنفصل الخدمة عن المتحكم. المتحكم لا يملك المصفوفة.

ماذا ستتعلم

  • @Injectable وتسجيل providers
  • uuid للمعرّف
  • 404 عند الغياب

ما الذي لن تبنيه في هذا المشروع

  • PostgreSQL
  • مستخدم يملك الملاحظة
  • ترقيم الصفحات

قبل أن تبدأ

مشروع الصدى، وفصل Providers.

من الدورة: 06-providers.

قواعد العمل

  • المعرّف يولَّد على الخادم لا من العميل.
  • العنوان مطلوب وغير فارغ.
  • الحذف لملاحظة غير موجودة 404 لا 204 صامت إن لم تجدها. إن وجدتها فـ 204.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /notes 201 ينشئ ملاحظة
GET /notes 200 كل الملاحظات، [] إن خلت
GET /notes/:id 200 واحدة أو 404
PATCH /notes/:id 200 يعدّل العنوان أو المتن
DELETE /notes/:id 204 يحذف

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new notes-memory. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. أنشئ NotesService فيها private notes = [].
  2. المتحكم يستدعي الخدمة فقط.
  3. ارفض عنوانًا فارغًا بـ BadRequestException قبل أن تتعلم DTO. في المشروع 11 ستستبدله بأنبوب.
  4. اكتب createdAt بـ new Date().toISOString().

شكل مقترح

src/notes/notes.service.ts
src/notes/notes.controller.ts
src/notes/notes.module.ts

أصغر قطعة تبدأ منها

import { Injectable, NotFoundException } from "@nestjs/common";
import { randomUUID } from "node:crypto";

@Injectable()
export class NotesService {
  private readonly notes: Array<{ id: string; title: string }> = [];

  create(title: string) {
    const note = { id: randomUUID(), title };
    this.notes.push(note);
    return note;
  }

  findOne(id: string) {
    const note = this.notes.find((item) => item.id === id);
    if (!note) throw new NotFoundException();
    return note;
  }
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • وضع المصفوفة داخل المتحكم.
  • قبول id من الجسم.
  • إرجاع 404 لقائمة فارغة.

ينتهي المشروع عندما

  • الخمسة مسارات تعمل على الذاكرة.
  • خدمتان مسجّلتان في وحدتين مختلفتين لا تشاركان المصفوفة إن جرّبت ذلك. في هذا المشروع وحدة واحدة تكفي.

تمديد بعد الانتهاء

أضف بحثًا ?q= على العنوان من غير قاعدة.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 2» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
