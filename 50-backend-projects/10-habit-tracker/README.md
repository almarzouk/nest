# 10 — متتبع عادات

**المستوى:** مبتدئ  
**النوع:** Backend فقط  
**الأمر الذي تبدأ منه:** `nest new habit-tracker`

## ماذا تبني

عادة تتكرر كل يوم. تسجيل اليوم مرتين لنفس العادة مرفوض. سلسلة الأيام تُحسب على الخادم.

## لماذا هذا المشروع الآن

تختم المرحلة الأولى بقاعدة تمنع التكرار الزمني، لا بتكرار شكل الملاحظات.

## ماذا ستتعلم

- مفتاح مركب عادة+يوم
- 409
- حساب سلسلة من غير ثقة بالعميل

## ما الذي لن تبنيه في هذا المشروع

- إشعارات
- مناطق زمنية متعددة
- حسابات

## قبل أن تبدأ

دفتر المصروفات.

من الدورة: [06-providers](../../nestjs-arabic-course/06-providers/README.md).

## قواعد العمل

- اليوم YYYY-MM-DD يرسله العميل، والخادم لا يصدّق سلسلة streak في الجسم.
- تسجيل نفس اليوم مرتين 409.
- الحذف للتسجيل يُعاد به حساب السلسلة.
- السلسلة أيام متتالية تنتهي بآخر يوم مسجّل لا باليوم الحالي إن نسي المستخدم.

## عقد HTTP

| الطريقة | المسار | الرمز | ماذا يفعل |
| --- | --- | --- | --- |
| `POST` | `/habits` | 201 | ينشئ عادة |
| `POST` | `/habits/:id/check-ins` | 201 | يسجّل يومًا |
| `GET` | `/habits/:id` | 200 | العادة مع streak المحسوب |

القائمة الفارغة `200` بجسم `[]` أو غلاف بيانات، لا `404`. الإنشاء `201`. الغائب `404`. التعارض `409`. الدخل الرديء `400`.

## من الصفر

1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ `nest new habit-tracker`. اختر ESM عندما يسأل Nest CLI.
2. لا تنسخ `node_modules` إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
3. أبقِ `AppModule` جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل `main.ts`.
4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

## خطوات البناء

1. مفتاح التفرد habitId+day.
2. دالة streak تمشي الأيام للخلف من آخر تسجيل.
3. ارفض تاريخًا مستقبليًا.

## شكل مقترح

```text
src/habits/streak.ts
src/habits/habits.service.ts
```

## أصغر قطعة تبدأ منها

```ts
export function streakEndingAt(days: string[], last: string) {
  const set = new Set(days);
  let count = 0;
  const cursor = new Date(last + "T00:00:00Z");
  while (set.has(cursor.toISOString().slice(0, 10))) {
    count += 1;
    cursor.setUTCDate(cursor.getUTCDate() - 1);
  }
  return count;
}
```

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

## أخطاء تظهر هنا كثيرًا

- قبول streak من العميل.
- مقارنة التواريخ بتوقيت محلي يتغير مع السيرفر.
- 201 عند تكرار اليوم.

## ينتهي المشروع عندما

- اليوم المكرر 409.
- ثلاثة أيام متتالية تعطي streak يساوي 3.
- انقطاع يوم يصفر ما بعده فقط.

## تمديد بعد الانتهاء

أضف GET /habits يعرض كل العادات مع سلسلتها.

## كيف نبنيه معًا

عندما تقول «ابدأ المشروع 10» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
