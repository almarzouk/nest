38 — ويب هوك صادر

المستوى: متقدم
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new outbound-webhooks

ماذا تبني

عند دفع الطلب ترسل حدثًا إلى عنوان سجّله الشريك. التوقيع HMAC. الفشل المؤقت يعيد المحاولة. النجاح لا يُكرر الأثر عندك.

لماذا هذا المشروع الآن

الشريك لا يقرأ قاعدتك. الحدث الخارج يحتاج توقيعًا ومحاولة ثانية.

ماذا ستتعلم

  • HMAC
  • سجل تسليم
  • إعادة على 503 لا على 400

ما الذي لن تبنيه في هذا المشروع

  • صندوق صادر كامل. التمهيد هنا والإكمال في المشروع 46.
  • كل أنواع الأحداث

قبل أن تبدأ

الدفع الوهمي وطابور BullMQ.

من الدورة: 61-webhooks.

قواعد العمل

  • السر في البيئة.
  • التوقيع على الجسم الخام الذي أرسلته.
  • 2xx تغلق التسليم.
  • 5xx وشبكة تعيد المحاولة بحد.
  • 4xx لا تعيد لأن العقد مرفوض.
  • معرّف الحدث ثابت عبر المحاولات.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /partners/:id/endpoints 201 يحفظ URL
GET /deliveries/:id 200 حالة التسليم

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new outbound-webhooks. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. عند الدفع أنشئ صف تسليم بمعرّف حدث.
  2. العامل يرسل POST مع الترويسة x-signature.
  3. مستقبل محلي صغير في الاختبار يعيد 503 مرة ثم 200.

شكل مقترح

src/webhooks/sign.ts
src/webhooks/delivery.processor.ts

أصغر قطعة تبدأ منها

export function sign(secret: string, body: Buffer) {
  return createHmac("sha256", secret).update(body).digest("hex");
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • توقيع الكائن بعد JSON.parse ثم stringify مختلف.
  • إعادة المحاولة على 400 إلى ما لا نهاية.
  • سر داخل المستودع.

ينتهي المشروع عندما

  • الحدث نفسه يُعاد بنفس المعرّف.
  • 200 يوقف المحاولات.
  • توقيع المستقبل التجريبي يطابق.
