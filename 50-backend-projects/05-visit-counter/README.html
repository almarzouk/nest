05 — عداد الزيارات

المستوى: مبتدئ
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new visit-counter

ماذا تبني

عداد واحد للتطبيق كله. قراءته لا تزيده. زيادته مسار مستقل. لا قائمة عدادات.

لماذا هذا المشروع الآن

تتعلم أن GET لا يغيّر الحالة، وأن المورد قد يكون مفردًا بلا :id.

ماذا ستتعلم

  • GET الآمن
  • POST للتغيير
  • رقم يعيش في الخدمة

ما الذي لن تبنيه في هذا المشروع

  • توزيع العد على عدة عمليات
  • Redis
  • مفتاح تكرار

قبل أن تبدأ

برطمان الاقتباسات.

من الدورة: 05-controllers.

قواعد العمل

  • GET /counter لا يغيّر القيمة.
  • POST /counter/hits يزيد واحدًا ويرجع القيمة الجديدة.
  • لا يوجد DELETE. إعادة التشغيل تعيد الصفر، ووثّق ذلك في رد GET بحقل volatile: true.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
GET /counter 200 القيمة الحالية
POST /counter/hits 200 يزيد ويعيد القيمة. ليس إنشاء مورد جديد كل مرة

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new visit-counter. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. ابدأ القيمة عند 0 داخل الخدمة.
  2. اكتب اختبارًا يدويًا: GET مرتين ثم POST ثم GET. الأولى والثانية متساويتان.
  3. ارفض جسمًا فيه amount من العميل. الزيادة دائمًا 1 حتى لا يضبط الزائر العداد.

شكل مقترح

src/counter/counter.service.ts
src/counter/counter.controller.ts

أصغر قطعة تبدأ منها

@Injectable()
export class CounterService {
  private hits = 0;
  read() {
    return { hits: this.hits, volatile: true };
  }
  hit() {
    this.hits += 1;
    return { hits: this.hits };
  }
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • زيادة العداد داخل GET.
  • قبول { amount: 1000 } من الجسم.
  • إنشاء صف جديد لكل ضغطة فتتحول الشاشة إلى قائمة.

ينتهي المشروع عندما

  • القراءة لا تكتب.
  • العميل لا يختار مقدار الزيادة.

تمديد بعد الانتهاء

أضف POST /counter/reset يحميه لاحقًا، والآن اتركه بلا حماية واكتب تعليقًا أن هذا ثقب تُغلقه في مشروع الأدوار.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 5» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
