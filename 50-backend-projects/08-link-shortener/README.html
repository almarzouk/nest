08 — مختصر روابط

المستوى: مبتدئ
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new link-shortener

ماذا تبني

ترسل عنوانًا طويلًا فترى رمزًا قصيرًا. زيارة الرمز تحوّل المتصفح إلى العنوان. الزيارة تُحسب.

لماذا هذا المشروع الآن

أول رد ليس JSON. @Redirect أو res.redirect بحذر، والعد زيادة حقيقية على GET للرابط القصير فقط لأن هذا عقد المختصر لا صفحة آمنة عامة.

ماذا ستتعلم

  • رمز قصير يولَّد على الخادم
  • 302
  • رفض ما ليس http أو https

ما الذي لن تبنيه في هذا المشروع

  • نطاق مخصص
  • مستخدمون
  • منع الروابط الخبيثة بقائمة خارجية

قبل أن تبدأ

بطاقات الدراسة.

من الدورة: 05-controllers.

قواعد العمل

  • الرمز 6 أحرف من مجموعة بلا التباس.
  • العنوان يبدأ بـ http:// أو https:// وإلا 400.
  • تكرار العنوان نفسه يعيد الرمز القديم ولا ينشئ ثانيًا.
  • GET /r/:code يزيد hits ثم يحوّل. GET /links للقائمة لا يزيد.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /links 201 ينشئ أو يعيد الموجود
GET /links 200 الإدارة بلا تحويل
GET /r/:code 302 تحويل أو 404

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new link-shortener. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. استخدم URL من جافاسكربت للتحقق.
  2. إن أعدت المورد الموجود فالرموز 200 لا 201. 201 للجديد فقط.
  3. للتحويل أعد كائن @Redirect أو اضبط Location. لا تخلط ذلك مع JSON.

شكل مقترح

src/links/links.service.ts
src/links/links.controller.ts

أصغر قطعة تبدأ منها

import { Controller, Get, Param, Redirect } from "@nestjs/common";

@Controller()
export class LinksController {
  @Get("r/:code")
  @Redirect()
  open(@Param("code") code: string) {
    const link = this.links.open(code);
    return { url: link.url, statusCode: 302 };
  }
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • الثقة بنص الرابط من غير URL.
  • 201 في كل مرة حتى للمكرر.
  • زيادة العداد على مسار الإدارة.

ينتهي المشروع عندما

  • رابط غير صالح 400.
  • الرمز المجهول 404.
  • نفس العنوان لا يصنع رمزين.

تمديد بعد الانتهاء

ارفض العناوين التي تشير إلى مضيفك نفسه حتى لا تصنع حلقة.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 8» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
