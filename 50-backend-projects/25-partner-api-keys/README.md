# 25 — مفاتيح الشركاء

**المستوى:** متوسط  
**النوع:** Backend فقط  
**الأمر الذي تبدأ منه:** `nest new partner-api-keys`

## ماذا تبني

شريك يُنشأ مرة، وترى مفتاحه في رد الإنشاء فقط. بعد ذلك يُخزَّن هاش. الطلبات إلى كتالوج الشريك تحمل المفتاح.

## لماذا هذا المشروع الآن

ليست كل هوية مستخدمًا بكلمة مرور. المفتاح سر يُعرض مرة.

## ماذا ستتعلم

- عرض مرة واحدة
- هاش للمفتاح
- حارس مستقل عن جلسة المتصفح

## ما الذي لن تبنيه في هذا المشروع

- تدوير معقد
- نطاقات صلاحيات كثيرة
- فوترة حسب النداء

## قبل أن تبدأ

الغلاف. الكتالوج هنا يمكن أن يكون قائمة طلبات وهمية للشريك.

من الدورة: [20-authentication](../../nestjs-arabic-course/20-authentication/README.md).

## قواعد العمل

- المفتاح العشوائي لا يُعاد في GET.
- التخزين هاش.
- غياب المفتاح أو خطؤه 401.
- مفتاح ملغى 401.
- لا تسجّل المفتاح في اللوج.

## عقد HTTP

| الطريقة | المسار | الرمز | ماذا يفعل |
| --- | --- | --- | --- |
| `POST` | `/partners` | 201 | يعيد المفتاح مرة |
| `GET` | `/partners` | 200 | بلا أسرار |
| `GET` | `/partner/orders` | 200 | بمفتاح صالح |

القائمة الفارغة `200` بجسم `[]` أو غلاف بيانات، لا `404`. الإنشاء `201`. الغائب `404`. التعارض `409`. الدخل الرديء `400`.

## من الصفر

1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ `nest new partner-api-keys`. اختر ESM عندما يسأل Nest CLI.
2. لا تنسخ `node_modules` إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
3. أبقِ `AppModule` جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل `main.ts`.
4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

## خطوات البناء

1. ولّد المفتاح بـ randomBytes وأظهره مرة.
2. الحارس يقرأ x-api-key ويطابق الهاش.
3. أضف revokedAt. إن وُجد فالمفتاح ميت.

## شكل مقترح

```text
src/partners/api-key.guard.ts
src/partners/partners.service.ts
```

## أصغر قطعة تبدأ منها

```ts
create() {
  const plain = randomBytes(24).toString("base64url");
  this.keys.push({ hash: this.hash(plain), revokedAt: null });
  return { apiKey: plain };
}
```

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

## أخطاء تظهر هنا كثيرًا

- حفظ المفتاح كما هو.
- إرجاعه في قائمة الشركاء.
- استخدام مقارنة كلمة المرور البطيئة بشكل خاطئ ثم تسجيل السر عند الفشل.

## ينتهي المشروع عندما

- الاستدعاء الثاني لقائمة الشركاء لا يظهر المفتاح.
- المفتاح الملغى يفشل.
- مفتاح شريك لا يرى طلبات شريك آخر.

## تمديد بعد الانتهاء

أضف اسم نطاق مسموحًا به في الحارس وتجاهل الباقي.

## كيف نبنيه معًا

عندما تقول «ابدأ المشروع 25» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
