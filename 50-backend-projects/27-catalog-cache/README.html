27 — كتالوج مخزّن مؤقتًا

المستوى: متوسط
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new catalog-cache

ماذا تبني

قائمة المنتجات تُقرأ كثيرًا. تخزّن الرد ثواني ثم تبطله عند الإنشاء أو تعديل السعر.

لماذا هذا المشروع الآن

التخزين المؤقت من غير إبطال يعرض سعرًا قديمًا. هذا هو الدرس لا تركيب الحزمة.

ماذا ستتعلم

  • CacheModule
  • مفتاح يشمل الاستعلام
  • invalidate عند الكتابة

ما الذي لن تبنيه في هذا المشروع

  • Redis إلزامي. ابدأ بالذاكرة ثم اذكر Redis كتمديد.
  • تخزين بيانات مستخدم خاص

قبل أن تبدأ

الكتالوج المرقم.

من الدورة: 33-caching.

قواعد العمل

  • المفتاح يضم category و page و sort.
  • TTL قصير، 30 ثانية مثلًا.
  • POST منتج يحذف مفاتيح القائمة.
  • لا تخزّن /me ولا السلة.
  • الرد يضم generatedAt حتى ترى إن كان قديمًا أثناء التعلم، واحذفه إن صار عقدًا عامًا.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
GET /products 200 قد يأتي من الذاكرة المؤقتة
POST /products 201 يبطل القائمة

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new catalog-cache. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. لف القراءة. إن وُجد المفتاح أعده.
  2. بعد الكتابة امسح بادئة المفاتيح أو المفتاح المعروف.
  3. اثبت بتجربة: أنشئ منتجًا ثم اقرأ فورًا وتوقع ظهوره.

شكل مقترح

src/products/products.service.ts

أصغر قطعة تبدأ منها

async list(key: string) {
  const cached = await this.cache.get(key);
  if (cached) return cached;
  const fresh = this.compute();
  await this.cache.set(key, fresh, 30_000);
  return fresh;
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • مفتاح ثابت list بينما الاستعلام يتغير.
  • نسيان الإبطال بعد PATCH السعر.
  • تخزين خطأ 500.

ينتهي المشروع عندما

  • استعلامان مختلفان لا يتقاسمان الرد.
  • الكتابة تظهر في القراءة التالية.
  • مسار خاص بالمستخدم غير مخزّن.

تمديد بعد الانتهاء

انقل المخزن إلى Redis من غير تغيير عقد HTTP.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 27» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
