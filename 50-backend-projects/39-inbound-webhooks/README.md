# 39 — ويب هوك وارد

**المستوى:** متقدم  
**النوع:** Backend فقط  
**الأمر الذي تبدأ منه:** `nest new inbound-webhooks`

## ماذا تبني

تستقبل حدث دفع من مزود. تتحقق من التوقيع على rawBody. تكرار event id لا يخصم ولا يفعّل مرتين.

## لماذا هذا المشروع الآن

المزود يعيد الإرسال. صفحة النجاح ليست مصدر الحقيقة.

## ماذا ستتعلم

- rawBody: true
- قيد فريد على event id
- 400 للتوقيع و 200 للمكرر

## ما الذي لن تبنيه في هذا المشروع

- Stripe SDK كامل
- كل أنواع الأحداث

## قبل أن تبدأ

الصندوق الصادر مفهومًا، وهذا هو الاتجاه المعاكس.

من الدورة: [61-webhooks](../../nestjs-arabic-course/61-webhooks/README.md).

## قواعد العمل

- NestFactory.create مع rawBody: true.
- التوقيع الخاطئ 400 ولا يُعاد كخطأ مؤقت إن كان العقد كذلك. وثّق أن المزود قد لا يعيد 400.
- الحدث المكرر 200 من غير أثر ثانٍ.
- لا تفعّل الطلب قبل نجاح التوقيع.

## عقد HTTP

| الطريقة | المسار | الرمز | ماذا يفعل |
| --- | --- | --- | --- |
| `POST` | `/webhooks/payments` | 200 | بعد توقيع صحيح |

القائمة الفارغة `200` بجسم `[]` أو غلاف بيانات، لا `404`. الإنشاء `201`. الغائب `404`. التعارض `409`. الدخل الرديء `400`.

## من الصفر

1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ `nest new inbound-webhooks`. اختر ESM عندما يسأل Nest CLI.
2. لا تنسخ `node_modules` إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
3. أبقِ `AppModule` جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل `main.ts`.
4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

## خطوات البناء

1. فعّل rawBody.
2. احسب HMAC وقارن بتوقيت ثابت إن توفرت الدالة، وإلا قارن بحذر موثّق.
3. أدرج event id بقيد فريد قبل تغيير حالة الطلب.

## شكل مقترح

```text
src/main.ts
src/webhooks/payments-webhook.controller.ts
```

## أصغر قطعة تبدأ منها

```ts
const app = await NestFactory.create(AppModule, { rawBody: true });
```

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

## أخطاء تظهر هنا كثيرًا

- التحقق من JSON المعاد تسلسله.
- تفعيل الطلب لأن المسار رجع إلى المتصفح.
- 500 على المكرر فيعيد المزود الإرسال إلى الأبد.

## ينتهي المشروع عندما

- توقيع خاطئ لا يغيّر الطلب.
- نفس الحدث مرتين أثر واحد.
- الجسم يُقرأ من rawBody.

## تمديد بعد الانتهاء

ارفض حدثًا أقدم من خمس دقائق.

## كيف نبنيه معًا

عندما تقول «ابدأ المشروع 39» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
