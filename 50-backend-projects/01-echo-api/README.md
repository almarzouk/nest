# 01 — صدى الطلب

**المستوى:** مبتدئ  
**النوع:** Backend فقط  
**الأمر الذي تبدأ منه:** `nest new echo-api`

## ماذا تبني

خدمة تعيد إليك ما أرسلته: الطريقة، والمسار، وجسمًا صغيرًا، وقائمة قصيرة من الترويسات. لا قاعدة بيانات ولا مستخدمون.

## لماذا هذا المشروع الآن

قبل حفظ أي شيء تحتاج أن ترى الطلب يخرج من Nest كما دخل. هذا المشروع يثبت أن المتحكم يستقبل وأنت تعيد قيمة، وNest تكتب JSON.

## ماذا ستتعلم

- @Controller و @Post و @Get
- إرجاع كائن بدل res.send
- قراءة @Body و @Headers بشكل ضيق

## ما الذي لن تبنيه في هذا المشروع

- حفظ في الذاكرة
- ValidationPipe
- مصادقة

## قبل أن تبدأ

الفصلان 02 و 05 من الدورة، أو ما يكفي لتشغيل nest new ورؤية مسار GET.

من الدورة: [05-controllers](../../nestjs-arabic-course/05-controllers/README.md).

## قواعد العمل

- الصدى لا يخزّن شيئًا بين الطلبات.
- لا تعِد كل الترويسات. قائمة بيضاء: user-agent و x-request-id إن وُجد.
- الجسم إن زاد عن حقول message و tags تتجاهل الزائد أو ترفضه. اختر الرفض بـ 400 عندما تتعلم الأنبوب، وفي هذا المشروع تجاهل الزائد ووثّق ذلك.

## عقد HTTP

| الطريقة | المسار | الرمز | ماذا يفعل |
| --- | --- | --- | --- |
| `GET` | `/echo` | 200 | يعيد method و path من غير جسم |
| `POST` | `/echo` | 200 | يعيد method و message و tags. هذا ليس إنشاء مورد فلا تستخدم 201 |

القائمة الفارغة `200` بجسم `[]` أو غلاف بيانات، لا `404`. الإنشاء `201`. الغائب `404`. التعارض `409`. الدخل الرديء `400`.

## من الصفر

1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ `nest new echo-api`. اختر ESM عندما يسأل Nest CLI.
2. لا تنسخ `node_modules` إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
3. أبقِ `AppModule` جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل `main.ts`.
4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

## خطوات البناء

1. ولّد وحدة echo وكنترولرًا. اترك الخدمة فارغة أو بلا وجود إن لم تحتجها.
2. ابنِ دالة تأخذ body اختياريًا وتُرجع { method, path, message, tags }.
3. جرّب curl للمسارين. تأكد أن إعادة التشغيل لا تتذكر الرسالة السابقة.
4. أضف حدًا: tags إن لم تكن مصفوفة نصوص فأرجِع 400 باستثناء HttpException بسيطًا.

## شكل مقترح


## أصغر قطعة تبدأ منها

```ts
import { Body, Controller, Get, Post } from "@nestjs/common";

@Controller("echo")
export class EchoController {
  @Get()
  ping() {
    return { method: "GET", path: "/echo" };
  }

  @Post()
  mirror(@Body() body: { message?: string }) {
    return { method: "POST", path: "/echo", message: body.message ?? "" };
  }
}
```

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

## أخطاء تظهر هنا كثيرًا

- استخدام 201 لأن الطريقة POST.
- كتابة res.json مع return في الوقت نفسه.
- تخزين آخر جسم في متغير على مستوى الملف فيصير للخادم ذاكرة لم تطلبها.

## ينتهي المشروع عندما

- GET و POST يعملان.
- إعادة التشغيل تمسح أي انطباع بأن الرسالة حُفظت.
- تستطيع شرح من يكتب JSON: Nest بعد return.

## تمديد بعد الانتهاء

أضف GET /echo/headers يعيد الترويسات المسموحة فقط.

## كيف نبنيه معًا

عندما تقول «ابدأ المشروع 1» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
