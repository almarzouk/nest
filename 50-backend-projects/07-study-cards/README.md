# 07 — بطاقات دراسة

**المستوى:** مبتدئ  
**النوع:** Backend فقط  
**الأمر الذي تبدأ منه:** `nest new study-cards`

## ماذا تبني

بطاقة فيها وجه وظهر. المراجعة تنقلها إلى صندوق أعلى وتؤجل موعدها. قائمة اليوم هي المستحق فقط.

## لماذا هذا المشروع الآن

القاعدة ليست حفظ صف. القاعدة موعد وحالة تتغير بعد فعل المستخدم.

## ماذا ستتعلم

- تصفية بالتاريخ
- فعل review غير CRUD العام
- صناديق 1 و 2 و 3

## ما الذي لن تبنيه في هذا المشروع

- خوارزمية SM-2 كاملة
- حسابات طلاب
- مزامنة أجهزة

## قبل أن تبدأ

دفتر العناوين.

من الدورة: [06-providers](../../nestjs-arabic-course/06-providers/README.md).

## قواعد العمل

- الصندوق يبدأ عند 1 والموعد الآن.
- مراجعة ناجحة ترفع الصندوق حتى 3 وتضاعف التأجيل بالأيام.
- فشل المراجعة يعيد الصندوق إلى 1 والموعد إلى الآن.
- GET /cards يعيد الكل. GET /cards/due يعيد المستحق.

## عقد HTTP

| الطريقة | المسار | الرمز | ماذا يفعل |
| --- | --- | --- | --- |
| `POST` | `/cards` | 201 | وجه وظهر |
| `GET` | `/cards/due` | 200 | dueAt <= الآن |
| `POST` | `/cards/:id/reviews` | 200 | جسم { remembered: boolean } |

القائمة الفارغة `200` بجسم `[]` أو غلاف بيانات، لا `404`. الإنشاء `201`. الغائب `404`. التعارض `409`. الدخل الرديء `400`.

## من الصفر

1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ `nest new study-cards`. اختر ESM عندما يسأل Nest CLI.
2. لا تنسخ `node_modules` إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
3. أبقِ `AppModule` جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل `main.ts`.
4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

## خطوات البناء

1. خزّن dueAt كسلسلة ISO.
2. قارن بـ Date.parse لا بنص خام.
3. ارفض وجهًا فارغًا.

## شكل مقترح

```text
src/cards/cards.service.ts
src/cards/cards.controller.ts
```

## أصغر قطعة تبدأ منها

```ts
review(id: string, remembered: boolean) {
  const card = this.findOne(id);
  if (remembered) {
    card.box = Math.min(3, card.box + 1);
    const days = card.box;
    card.dueAt = new Date(Date.now() + days * 86400000).toISOString();
  } else {
    card.box = 1;
    card.dueAt = new Date().toISOString();
  }
  return card;
}
```

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

## أخطاء تظهر هنا كثيرًا

- وضع due داخل مسار GET فيغيّر البطاقة.
- مقارنة تواريخ كنصوص بترتيبات مختلفة.
- صندوق رابع بلا سبب.

## ينتهي المشروع عندما

- بطاقة جديدة تظهر في due.
- مراجعة ناجحة تخرجها من due حتى يحين الموعد.

## تمديد بعد الانتهاء

أضف حدًا 20 بطاقة مستحقة في الرد حتى لا يثقل اليوم.

## كيف نبنيه معًا

عندما تقول «ابدأ المشروع 7» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
