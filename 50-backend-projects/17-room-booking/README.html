17 — حجز غرف

المستوى: متوسط
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new room-booking

ماذا تبني

غرفة تُحجز ببداية ونهاية. حجز يتداخل مع آخر على نفس الغرفة يُرفض. النهاية الملامسة للبداية التالية مسموحة.

لماذا هذا المشروع الآن

قاعدة التداخل أشهر مصدر لأخطاء 200 الكاذبة.

ماذا ستتعلم

  • مقارنة فترات
  • 409
  • التحقق من start < end

ما الذي لن تبنيه في هذا المشروع

  • تقويم خارجي
  • تكرار أسبوعي
  • دفع

قبل أن تبدأ

التصويت.

من الدورة: 06-providers.

قواعد العمل

  • الأوقات ISO.
  • end بعد start.
  • التداخل على نفس roomId فقط.
  • إن انتهت حجزة 10:00 وبدأت الأخرى 10:00 فلا تعارض.
  • الإلغاء يحرر الفترة.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /rooms 201 غرفة
POST /rooms/:id/bookings 201 حجز أو 409
DELETE /bookings/:id 204 إلغاء

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new room-booking. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. اكتب overlaps(a, b) واختبر أربع حالات على الورق قبل الكود.
  2. لا تعتمد على ترتيب وصول الحجوزات في المصفوفة.
  3. غرفة غير موجودة 404.

شكل مقترح

src/bookings/overlaps.ts
src/bookings/bookings.service.ts

أصغر قطعة تبدأ منها

export function overlaps(a: { start: number; end: number }, b: { start: number; end: number }) {
  return a.start < b.end && b.start < a.end;
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • استخدام <= في الطرفين فيُرفض التلامس.
  • مقارنة سلاسل تواريخ بترتيب معجمي خاطئ.
  • فحص غرفة واحدة ونسيان أن الغرف الأخرى حرة.

ينتهي المشروع عندما

  • تداخل واضح 409.
  • تلامس الأطراف 201.
  • بعد الإلغاء تُقبل الفترة.

تمديد بعد الانتهاء

أضف GET لجدول الغرفة في يوم واحد.

كيف نبنيه معًا

عندما تقول «ابدأ المشروع 17» نفتح مشروع Nest فارغًا وننفّذ خطوة واحدة في كل مرة: مسار، ثم قاعدة، ثم خطأ متوقع، ثم اختبارًا صغيرًا إن كان الفصل قد وصل إليه. لا نلصق الحل كاملًا قبل أن ترى الطلب يفشل للسبب الصحيح.
