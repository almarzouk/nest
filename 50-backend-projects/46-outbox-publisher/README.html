46 — صندوق صادر

المستوى: إنتاج
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new outbox-publisher

ماذا تبني

حفظ الطلب وصف الحدث في معاملة واحدة. ناشر لاحق يرسل ما لم يُنشر. سقوط العملية بعد الحفظ لا يضيع الحدث.

لماذا هذا المشروع الآن

إطلاق الحدث بعد المعاملة يضيع. إطلاقه قبلها يرسل حدثًا لحفظ لم يحدث.

ماذا ستتعلم

  • outbox
  • معاملة
  • ناشر يعيد المحاولة

ما الذي لن تبنيه في هذا المشروع

  • Kafka كمنتج إلزامي. جدول وناشر يكفيان.
  • ضبط سير عمل طويل

قبل أن تبدأ

الطلبات والويب هوك الصادر.

من الدورة: 66-reliability.

قواعد العمل

  • صف Outbox في نفس transaction مع الطلب.
  • الناشر يعلّم publishedAt بعد نجاح الإرسال.
  • إعادة التشغيل تكمل غير المنشور.
  • لا ترسل من داخل معاملة مفتوحة عبر الشبكة.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /orders 201 طلب وصف صندوق
GET /outbox?status=pending 200 للتعلم

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new outbox-publisher. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. اكتب الصف داخل $transaction.
  2. عامل يقرأ pending ويرسل ثم يحدّث.
  3. اقتل العملية بعد الحفظ وقبل الإرسال وتأكد أن الصف بقي.

شكل مقترح

src/outbox/outbox.publisher.ts
prisma/schema.prisma

أصغر قطعة تبدأ منها

await this.prisma.$transaction(async (tx) => {
  const order = await tx.order.create({ data });
  await tx.outbox.create({ data: { type: "order.created", payload: { orderId: order.id } } });
});

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • emit ثم insert.
  • insert ثم emit من غير جدول.
  • تعليم المنشور قبل رد الشريك 2xx.

ينتهي المشروع عندما

  • لا طلب بلا صف صندوق في النجاح.
  • الناشر يفرّغ المعلّق بعد العودة.
  • الشبكة لا تُستدعى داخل المعاملة.

تمديد بعد الانتهاء

أضف قفلًا حتى لا ينشر عاملان نفس الصف.

كيف نبنيه معًا
