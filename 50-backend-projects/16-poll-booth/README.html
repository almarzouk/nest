16 — غرفة تصويت

المستوى: متوسط
النوع: Backend فقط
الأمر الذي تبدأ منه: nest new poll-booth

ماذا تبني

استطلاع بخيارات تُثبَّت عند الإنشاء. المصوّت يُعرف بمفتاح يرسله في ترويسة، ويصوّت مرة واحدة حتى إغلاق الاستطلاع.

لماذا هذا المشروع الآن

القيد على الفعل لا على شكل الصف فقط. الترويسة هنا هوية مؤقتة قبل مشروع الحسابات.

ماذا ستتعلم

  • ترويسة مطلوبة
  • 409 على الصوت الثاني
  • إغلاق يمنع الزيادة

ما الذي لن تبنيه في هذا المشروع

  • حسابات حقيقية
  • تصويت سري مشفّر
  • واجهة نتائج حية

قبل أن تبدأ

الوصفات.

من الدورة: 13-guards.

قواعد العمل

  • الخيارات من 2 إلى 6 ولا تتغير بعد الإنشاء.
  • الترويسة x-voter-key مطلوبة للتصويت.
  • الصوت الثاني لنفس المفتاح 409.
  • بعد الإغلاق التصويت 409 والنتائج تبقى مقروءة.

عقد HTTP

الطريقة المسار الرمز ماذا يفعل
POST /polls 201 سؤال وخيارات
POST /polls/:id/votes 201 صوت واحد
POST /polls/:id/close 200 يغلق
GET /polls/:id 200 الأعداد من غير مفاتيح المصوتين

القائمة الفارغة 200 بجسم [] أو غلاف بيانات، لا 404. الإنشاء 201. الغائب 404. التعارض 409. الدخل الرديء 400.

من الصفر

  1. أنشئ مجلدًا فارغًا خارج هذا الدليل التعليمي، ثم نفّذ nest new poll-booth. اختر ESM عندما يسأل Nest CLI.
  2. لا تنسخ node_modules إلى مجلد الدليل. هذا المجلد للشرح، والكود يعيش في مشروعك.
  3. أبقِ AppModule جذرًا يسجّل وحدة الميزة. لا تضع القاعدة داخل main.ts.
  4. ابنِ بالترتيب الموجود تحت «خطوات البناء». لا تقفز إلى آخر مسار قبل أن يعمل الأول.

خطوات البناء

  1. لا تُرجع قائمة المفاتيح في GET. الأعداد فقط.
  2. خزّن المفاتيح في مجموعة لكل استطلاع.
  3. خيار خارج القائمة 400.

شكل مقترح

src/polls/polls.service.ts

أصغر قطعة تبدأ منها

vote(pollId: string, optionId: string, voterKey: string) {
  if (this.voters.get(pollId)?.has(voterKey)) {
    throw new ConflictException("already voted");
  }
}

هذه القطعة بداية لا مشروعًا مكتملًا. أكمل القواعد والمسارات بنفسك، ثم ارجع إلى العقد في الأعلى.

أخطاء تظهر هنا كثيرًا

  • إظهار مفاتيح المصوتين في النتائج.
  • السماح بتعديل الخيارات بعد أول صوت.
  • عد الصوت في العميل.

ينتهي المشروع عندما

  • الصوت المكرر 409.
  • النتيجة بلا هويات.
  • الإغلاق يوقف التصويت ولا يمسح الأعداد.
